# 사용 도구·모델·자산 라이선스 정리

수익 채널에 올리기 전에 아래 항목을 **각 공식 페이지에서 최신 조건으로 다시 확인**하세요. (2026-10 기준 정리, 법률 자문 아님)

| YouTube Data API v3 | Google API 서비스 약관 | 무료 (일일 할당량) | 할당량, OAuth 앱 검증 상태 |

| SDXL 1.0 base (stabilityai) | CreativeML Open RAIL++-M | 무료 | 상업적 이용 가능, 사용 제한 조항(유해 용도 금지) 준수 |

| FLUX.1 [dev] | FLUX.1 [dev] Non-Commercial License | — | **비상업 라이선스 — 수익 채널에 사용 금지(별도 상업 라이선스 필요)** |
| 유료 이미지 API (예: 클라우드 생성 서비스) | 각 서비스 약관 | 장당 수십 원 수준 | 필수 아님. 이 프로젝트는 기본적으로 사용하지 않음 |
