# 글꼴

한글 `.ttf`/`.otf` 파일을 이 폴더에 넣으면 우선 사용합니다 (이름에 Bold가 들어간 파일 우선).
비워 두면 운영체제 기본 한글 글꼴(Windows: 맑은 고딕, macOS: Apple SD 산돌고딕 Neo)을 씁니다.

상업적 이용이 자유로운 추천 글꼴 (SIL Open Font License):
- 나눔스퀘어라운드 / 나눔고딕 — 네이버 (https://hangeul.naver.com/font)
- Noto Sans KR — Google Fonts (https://fonts.google.com/noto/specimen/Noto+Sans+KR)

> 맑은 고딕·Apple SD 산돌고딕 Neo는 운영체제에 포함된 글꼴입니다. 영상에 사용하는 것은 일반적으로
> 허용되지만, 수익 채널에서는 OFL 글꼴을 넣어 두는 쪽이 가장 안전합니다.

이 폴더의 글꼴 파일은 Git에 올라가지 않습니다.
