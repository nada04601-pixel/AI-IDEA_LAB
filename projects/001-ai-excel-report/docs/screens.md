# 001. AI Excel 보고서 자동생성기

# 화면설계서

> 기준 문서: `idea.md`, `requirements.md`, `features.md`
> 와이어프레임은 구조와 배치를 보여주기 위한 텍스트 스케치이며, 실제 디자인은 개발 단계에서 정한다.
> `(가정)` 표시는 확인 전 임시 결정이다.

---

## 1. 화면 설계 원칙

1. **하나의 작업 = 6단계 마법사(Wizard).** 사용자는 한 화면에서 한 가지 결정만 한다.
2. **AI가 한 일은 항상 보이게, 확정은 사용자가 한다.** 신뢰도와 근거를 표시하고, 낮은 항목은 눈에 띄게 강조한다.
3. **오류는 숨기지 않는다.** 정규화 실패 행과 제외된 행 수를 결과 화면까지 끌고 간다.
4. **반복 사용자를 우선한다.** 두 번째 작업부터는 이전 매핑이 기본값으로 채워져서 확인만 하고 넘어가게 한다.
5. 데스크톱 브라우저 기준으로 설계한다. 모바일 최적화는 MVP 제외.

## 3. 화면 이동 흐름

```
[S-01 로그인]
     ↓
[홈 = S-08 작업 이력 목록] ──(새 작업)──→ [S-02 업로드]
     ↑                                         ↓
     │                                    [S-03 템플릿 선택]
     │                                         ↓
     │                                    [S-04 데이터 확인]
     │                                         ↓
     │                                    [S-05 컬럼 매핑]
     │                                         ↓
     │                                    [S-06 정규화 확인]
     │                                         ↓ (보고서 생성)
     └──────────────(완료 후 이동)──────── [S-07 결과]

[S-08] ──(행 클릭)──→ [S-09 이력 상세] ──(같은 매핑으로 새 작업)──→ [S-02]
```

- 로그인 후 첫 화면은 **작업 이력 목록**이며, 이력이 없으면 "첫 보고서 만들기" 안내를 보여준다.
- 마법사 도중 "이전" 버튼으로 돌아갈 수 있다. 앞 단계의 입력을 바꾸면 이후 단계 결과는 초기화한다는 안내를 띄운다.
- 마법사 도중 브라우저를 닫아도 진행 중 작업은 **임시 저장하지 않는다.** (MVP 단순화, 가정)

## 4. 공통 요소

### 4-1. 상단 헤더
```
[로고]  AI Excel 보고서        [새 작업]  [작업 이력]        [사용자 이메일 ▾ 로그아웃]
```

### 4-2. 단계 표시 (S-02 ~ S-07 공통)
```
① 파일 업로드 ─ ② 템플릿 선택 ─ ③ 데이터 확인 ─ ④ 컬럼 매핑 ─ ⑤ 정규화 확인 ─ ⑥ 결과
   (현재 단계 강조, 완료 단계는 체크 표시)
```

### 4-3. 하단 버튼 영역
```
[← 이전]                                           [다음 →]
```
- 다음 조건을 만족하지 않으면 "다음" 버튼은 비활성화되고, 버튼 옆에 **이유**를 한 줄로 표시한다.

### 4-4. 공통 상태 표시

| 상태 | 표시 방식 |
|---|---|
| 로딩 | 진행 표시줄 + 현재 작업 설명 ("컬럼을 분석하는 중...") |
| 오류 | 화면 상단 경고 배너, 사용자가 이해할 수 있는 사유와 다음 행동 안내 |
| 빈 상태 | 안내 문구 + 다음 행동 버튼 |
| 성공 | 완료 메시지 (토스트, 3초) |

## S-02 새 작업 1단계: 파일 업로드

**관련 기능**: F-001

```
① 파일 업로드 ─ ② ─ ③ ─ ④ ─ ⑤ ─ ⑥

  ┌──────────────────────────────────────┐
  │                                      │
  │     Excel 또는 CSV 파일을 끌어다 놓거나     │
  │            [ 파일 선택 ]               │
  │                                      │
  │   .xlsx, .csv / 최대 10MB / 50,000행    │
  └──────────────────────────────────────┘

  (업로드 후)
  파일명: 9월_매출.xlsx   크기: 1.2MB   [변경]
  시트 선택: [ Sheet1 ▾ ]       ← 시트가 2개 이상일 때만 표시
  데이터 행 수: 1,240행

                                            [다음 →]
```

| 요소 | 동작 |
|---|---|
| 업로드 영역 | 드래그&드롭 또는 클릭 선택 |
| 시트 선택 | 시트가 여러 개일 때만 표시, 기본값은 첫 시트 |
| 파일 변경 | 기존 업로드를 버리고 다시 선택 |
| 다음 | 업로드 성공 후 활성화 |

- **오류 표시**: 지원하지 않는 형식, 용량 초과, 행 수 초과, 암호 걸린 파일, 손상된 파일, 데이터가 없는 파일

## S-03 새 작업 2단계: 템플릿 선택

**관련 기능**: F-002

```
① ✓ ─ ② 템플릿 선택 ─ ③ ─ ④ ─ ⑤ ─ ⑥

  보고서 양식을 선택하세요

  ┌────────────────────────┐   ┌────────────────────────┐
  │ (●) 거래처별/상태별 매출   │   │ ( ) (추후 추가)          │
  │     보고서               │   │                        │
  │ 필요 항목: 고객사*, 거래일자*│   │                        │
  │ 매출금액*, 처리상태, 부서   │   │                        │
  │ (* 필수)                │   │                        │
  └────────────────────────┘   └────────────────────────┘

  선택한 양식 미리보기: [양식 보기]

  [← 이전]                                    [다음 →]
```

- 카드 선택 방식. 선택한 템플릿의 **필요 필드 목록(필수 표시)** 을 카드 안에 보여준다.
- "양식 보기"를 누르면 템플릿의 빈 양식을 표로 보여준다.
- 템플릿이 하나뿐이면 기본 선택 상태로 둔다. (가정)
- 선택 전에는 "다음" 비활성화, 이유: "보고서 양식을 선택하세요"

## S-04 새 작업 3단계: 데이터 확인

**관련 기능**: F-003

```
① ✓ ─ ② ✓ ─ ③ 데이터 확인 ─ ④ ─ ⑤ ─ ⑥

  헤더 행: [ 1 ] 행    ← 자동 감지됨, 틀리면 수정
  [경고] 병합 셀이 3곳 발견되었습니다. (3행, 5행, 8행)

  컬럼 분석 결과
  ┌──────────┬────────┬────────┬───────────────────────┐
  │ 컬럼명     │ 추정 타입 │ 빈 값    │ 샘플                    │
  ├──────────┼────────┼────────┼───────────────────────┤
  │ 거래처     │ 문자     │ 0%     │ (주)대한상사, 대한상사, ...  │
  │ 매출일     │ 날짜     │ 0%     │ 2026-09-01, 2026.09.02 │
  │ 금액       │ 숫자     │ 2%     │ 1000000, 1360000, ...  │
  │ ...      │        │        │                       │
  └──────────┴────────┴────────┴───────────────────────┘

  [← 이전]                                    [다음 →]
```

| 요소 | 동작 |
|---|---|
| 헤더 행 | 숫자 입력 또는 위/아래 버튼. 변경하면 표가 즉시 다시 분석됨 |
| 경고 | 병합 셀, 빈 행/열, 컬럼명 중복/누락을 목록으로 표시 |
| 컬럼 표 | 읽기 전용. 타입이 잘못 추정되면 헤더 행을 먼저 확인하도록 안내 |

- "다음"을 누르면 AI 매핑을 호출하므로, 다음 화면 진입 시 로딩이 있다.

## S-05 새 작업 4단계: 컬럼 매핑

**관련 기능**: F-004, F-005 (이 서비스의 핵심 화면)

```
① ✓ ─ ② ✓ ─ ③ ✓ ─ ④ 컬럼 매핑 ─ ⑤ ─ ⑥

  AI가 추천한 매핑입니다. 틀린 항목은 직접 바꿔주세요.   (AI 추천 / 규칙 기반 추천)

  ┌────────────┬───────────────┬────────┬────────────────┐
  │ 보고서 항목    │ 원본 컬럼       │ 신뢰도   │ 샘플 값           │
  ├────────────┼───────────────┼────────┼────────────────┤
  │ 고객사 *     │ [ 거래처 ▾ ]   │ ● 높음   │ (주)대한상사 ...   │
  │ 거래일자 *   │ [ 매출일 ▾ ]   │ ● 높음   │ 2026-09-01 ...  │
  │ 매출금액 *   │ [ 금액 ▾ ]     │ ● 높음   │ 1000000 ...     │
  │ 처리상태     │ [ 상태 ▾ ]     │ ◐ 중간   │ 완료, 진행 ...    │
  │ 부서        │ [ 선택 안 함 ▾ ] │ ○ 미매핑 │ -               │
  └────────────┴───────────────┴────────┴────────────────┘
   (신뢰도 낮음 / 미매핑 행은 배경색으로 강조)

  행에 마우스를 올리면: AI 판단 근거 한 줄 표시 ("컬럼명과 값이 매출 금액 형식과 일치")

  [!] 필수 항목 '매출금액'이 매핑되지 않았습니다.

  [← 이전]                              [매핑 확정하고 다음 →]
```

| 요소 | 동작 |
|---|---|
| 원본 컬럼 드롭다운 | 원본의 모든 컬럼 + "선택 안 함". 이미 다른 항목에 쓰인 컬럼은 표시를 달아 구분 |
| 신뢰도 | 높음(●) / 중간(◐) / 낮음 또는 미매핑(○). 색에만 의존하지 않고 기호도 함께 표시 |
| 샘플 값 | 선택한 컬럼의 값 3~5개. 드롭다운을 바꾸면 즉시 갱신 |
| 근거 | 마우스 오버(또는 행 펼침)로 AI 근거 표시 |
| 중복 지정 | 같은 컬럼을 두 항목에 지정하면 경고 표시 |
| 확정 버튼 | 필수 항목이 모두 매핑되어야 활성화. 비활성 이유를 버튼 옆에 표시 |
| 이전 매핑 불러옴 | 같은 템플릿으로 작업한 이력이 있으면 상단에 "지난 작업의 매핑을 불러왔습니다 [AI 추천으로 다시 받기]" 안내 (P1) |

- AI 호출이 실패하면 상단에 "AI 추천을 불러오지 못해 규칙 기반 추천을 표시합니다" 배너를 보여준다.
- 매핑 표 아래 오른쪽에 "원본 컬럼 중 사용되지 않는 컬럼: 담당자, 상품" 정보를 작게 표시한다.

## S-06 새 작업 5단계: 정규화 확인

**관련 기능**: F-006

```
① ✓ ─ ② ✓ ─ ③ ✓ ─ ④ ✓ ─ ⑤ 정규화 확인 ─ ⑥

  요약:  변환 완료 1,230건  /  오류 10건  /  거래처 통합 제안 4건

  [탭: 거래처 통합 제안 (4)] [탭: 오류 행 (10)] [탭: 변환 결과 샘플]

  ── 거래처 통합 제안 ──
  ┌───┬───────────────────────────────┬──────────────┐
  │ ☑ │ (주)대한상사, 대한상사 → 대한상사    │ 3건, 2건       │
  │ ☑ │ ㈜ABC테크, ABC테크 → ABC테크       │ 5건, 1건       │
  │ ☐ │ ...                           │              │
  └───┴───────────────────────────────┴──────────────┘
  체크한 항목만 같은 거래처로 통합됩니다.

  ── 오류 행 ──
  ┌───────┬────────┬──────────────────────┐
  │ 행 번호  │ 컬럼     │ 사유                    │
  ├───────┼────────┼──────────────────────┤
  │ 15     │ 거래일자  │ 날짜로 해석할 수 없음 (2026-13-45) │
  │ 88     │ 매출금액  │ 숫자가 아님 ("협의")       │
  └───────┴────────┴──────────────────────┘
  오류 행 처리:  (●) 제외하고 진행   ( ) 돌아가서 수정

  [← 이전]                              [보고서 생성 →]
```

| 요소 | 동작 |
|---|---|
| 요약 | 건수 3종을 상단에 고정 표시 |
| 거래처 통합 | 제안마다 체크박스. **기본값은 체크 해제** (BR-06: 자동 확정 금지). "모두 선택" 제공 |
| 오류 행 | 행 번호, 컬럼, 사유 표시. 오류 행이 있으면 "제외하고 진행"을 명시적으로 선택해야 다음으로 넘어감 |
| 변환 결과 샘플 | 변환 전/후를 나란히 5~10건 표시 (예: `2026.09.02` → `2026-09-02`) |
| 보고서 생성 | 누르면 집계와 생성을 실행하고 로딩 후 S-07로 이동 |

- 오류 행이 전체의 일정 비율(예: 30%, 가정) 이상이면 "데이터 상태가 좋지 않습니다. 헤더 행이나 매핑을 확인하세요" 경고를 띄운다.

## S-07 새 작업 6단계: 결과

**관련 기능**: F-007, F-008, F-009, F-010

```
① ✓ ─ ② ✓ ─ ③ ✓ ─ ④ ✓ ─ ⑤ ✓ ─ ⑥ 결과

  보고서가 생성되었습니다.
  거래처별_상태별_매출_20261002_1530.xlsx            [ ⬇ Excel 다운로드 ]

  처리 요약:  처리 1,230건 / 제외 10건 / 매출 합계 3,210,000원 / 검증 ✓ 일치

  [시트 탭: 거래처별 매출] [상태별 매출]

  미리보기 (상위 100행)
  ┌──────────┬────────────┐
  │ 거래처     │ 매출 합계     │
  ├──────────┼────────────┤
  │ 대한상사    │ 2,360,000  │
  │ ABC테크    │   850,000  │
  │ 합계       │ 3,210,000  │
  └──────────┴────────────┘
  * 서식은 실제 파일과 다를 수 있습니다. 전체 내용은 다운로드해서 확인하세요.

  [새 작업 시작]    [작업 이력 보기]
```

| 요소 | 동작 |
|---|---|
| 다운로드 | 생성 파일 `.xlsx` 즉시 다운로드 |
| 처리 요약 | 처리/제외 건수, 총합, 합계 검증 결과 표시 |
| 시트 탭 | 템플릿의 시트별로 전환 |
| 미리보기 실패 | "미리보기를 불러오지 못했습니다. 다운로드는 가능합니다" 표시, 다운로드는 정상 동작 |
| 새 작업 시작 | S-02로 이동 |

- **생성 중 화면**: "집계 중 → 보고서 작성 중 → 검증 중" 단계별 진행 표시
- **생성 실패 화면**: 실패 사유(예: 합계 검증 불일치, 템플릿 오류)와 [다시 시도] [이전 단계로] 버튼. 실패도 이력에 기록된다.

**관련 기능**: F-011 (로그인 후 홈 화면)

```
  작업 이력                                        [+ 새 작업]

  │ 2026-09-25 09:10│ 9월3주.xlsx │ 거래처별매출 │ 980│  0 │ 성공 │ 만료됨   │
```

- 행마다 삭제 아이콘. 삭제 시 확인 창을 띄운다. ("결과 파일도 함께 삭제됩니다")

## S-09 작업 이력 상세

**관련 기능**: F-010, F-011

```
  ← 목록으로

  9월_매출.xlsx → 거래처별/상태별 매출 보고서
  2026-10-02 15:30  /  상태: 성공

  [ ⬇ 결과 다운로드 ]      [ 같은 매핑으로 새 작업 ]      [ 삭제 ]

  처리 결과:  처리 1,230건 / 제외 10건 / 합계 3,210,000원

  사용한 매핑
  ┌────────────┬───────────┬──────────┐
  │ 보고서 항목    │ 원본 컬럼    │ 수정 여부   │
  ├────────────┼───────────┼──────────┤
  │ 고객사       │ 거래처      │ AI 추천    │
  │ 매출금액      │ 금액        │ 사용자 수정 │
  └────────────┴───────────┴──────────┘

  제외된 오류 행 (10건): [펼치기]
```

- **같은 매핑으로 새 작업**: S-02로 이동하며, 템플릿과 매핑이 미리 채워진다. 사용자는 파일만 올리면 되고 S-05에서는 확인만 한다.
- 실패한 작업은 상세에 실패 사유를 표시하고 다운로드 버튼은 숨긴다.
