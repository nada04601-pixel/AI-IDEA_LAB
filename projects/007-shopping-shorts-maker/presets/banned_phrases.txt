# 과장·허위 광고 소지 표현 — `ssm script --check`가 대본에서 찾으면 오류로 알린다 (기획서 Module 2).
# 근거: 표시·광고의 공정화에 관한 법률(확인할 수 없는 최상급·단정), 식품·화장품·의료기기 효능 광고 제한.
#
# 형식 (한 줄에 하나)
#   표현                      → 띄어쓰기를 무시하고 그대로 찾는다
#   re:정규식                 → 정규식으로 찾는다
#   ... => 대신 쓸 표현        → '=>' 뒤는 바꿔 쓸 표현 제안
# 이 목록에 없는 표현도 '확인할 수 없는 사실'이면 쓰지 않는다.

# 효과 단정
100% 효과 => 효과를 느끼는 분이 많아요
re:100\s*%\s*(만족|보장|해결|제거|차단) => 정도를 단정하지 않는 표현 (예: 훨씬 줄어요)
re:99(\.\d+)?\s*%\s*(제거|차단|살균|항균) => 시험 성적이 있을 때만, 없으면 빼기
무조건 효과 => 써보니 좋았어요
효과 보장 => 써보니 좋았어요
효과 입증 => 써보니 좋았어요
효능 입증 => (효능 표현 빼기)
부작용 없 => (안전성 단정 빼기)
부작용 제로 => (안전성 단정 빼기)
기적 => 생각보다 좋아요
만병통치 => (빼기)
평생 보장 => (보증 기간은 판매처 기준으로만)
영구적 => 오래 써도

# 가격·순위 (확인할 수 없는 최상급)
최저가 => 이 가격대에서
역대 최저 => 할인 중일 때
업계 최저 => 이 가격대에서
오늘만 이 가격 => 가격은 바뀔 수 있어요
re:(판매|만족도|매출|랭킹)\s*1\s*위 => 근거가 있을 때만 출처와 함께
세계 최초 => (빼기)
국내 유일 => (빼기)

# 의학·건강 효능 (일반 상품·식품·화장품 광고 금지)
완치 => (빼기)
치료 => (빼기, 의료기기 허가 상품만 가능)
치유 => (빼기)
질병 예방 => (빼기)
re:(면역력|혈압|혈당|콜레스테롤)\s*(강화|개선|조절|낮춰|낮춤|떨어) => (빼기)
re:(살|체지방|뱃살)이?\s*(쭉\s*)?빠(져|지는|짐) => (체중 효과 단정 빼기)
다이어트 효과 => (빼기)
의학적으로 => (빼기)
임상 => 시험 성적이 있을 때만
re:(의사|약사|전문가)(들)?(이|가)?\s*(추천|인정) => (근거 없는 인용 빼기)
FDA 승인 => 인증서가 있을 때만
식약처 인증 => 인증서가 있을 때만
