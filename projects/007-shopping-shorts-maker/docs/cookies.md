# 수집용 부계정 쿠키 준비

샤오홍슈·도우인은 로그인하지 않으면 영상 다운로드가 거의 막혀 있다. 그래서 로그인한 브라우저의 쿠키를 파일로 저장해 `ssm`이 쓰게 한다.

> **본계정 대신 부계정을 쓴다.** 자동 수집은 플랫폼 약관 위반 소지가 있어 계정이 제한될 수 있다.

## 1. 부계정 만들기

- 샤오홍슈(小红书), 도우인(抖音) 웹사이트에서 휴대폰 번호 등으로 새 계정을 만든다.
- 평소 쓰는 브라우저와 섞이지 않게 **Chrome 새 프로필**을 하나 만들어 그 프로필에서만 로그인하는 것을 권장한다.

## 2. 쿠키 파일로 내보내기

1. 그 Chrome 프로필에 쿠키 내보내기 확장 프로그램을 설치한다 (Netscape `cookies.txt` 형식으로 내보내는 것. 예: "Get cookies.txt LOCALLY").
2. 샤오홍슈(또는 도우인) 사이트에 로그인한 상태에서 확장 아이콘 → **Export**.
3. 받은 파일 이름을 `cookies.txt`로 바꿔 이 프로젝트의 `secrets/` 폴더에 넣는다.
   - 두 사이트를 모두 쓰면 한 파일에 합쳐도 된다 (내용을 이어 붙이면 된다).
4. `ssm doctor`에서 "부계정 쿠키"가 통과로 바뀌는지 확인한다.

다른 위치에 두려면 `config.local.yaml`에 경로를 적는다:

```yaml
collector:
  cookies_file: D:/secrets/cookies.txt
```

## 주의

- 쿠키 파일은 **비밀번호와 같다.** 다른 사람에게 보내거나 Git에 올리지 않는다 (`secrets/`는 Git 제외).
- 쿠키는 몇 주~몇 달 뒤 만료된다. 수집이 "로그인 필요"로 실패하면 2번을 다시 하면 된다.
- 다운로드가 계속 막히면 영상을 직접 받아 `ssm new --local 파일1.mp4 파일2.mp4`로 넣을 수 있다.
