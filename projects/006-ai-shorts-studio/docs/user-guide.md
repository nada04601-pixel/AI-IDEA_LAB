# AI Shorts Studio 사용 가이드

쇼츠 주제를 넣으면 대본 → 장면 → 이미지·영상 → 검토·승인 → 음성·자막 → 최종 MP4까지 한 화면에서 만드는 개인용 도구입니다.

> 기본은 모든 AI 기능이 **mock(연습용 가짜 생성기)** 입니다. 외부 AI를 부르지 않으므로 비용이 들지 않고, 결과물은 "MOCK IMAGE" 그림과 짧은 소리로 된 음성입니다. 이미지와 영상은 Google Gemini(Veo)로 실제 생성할 수 있습니다 (유료, [3. 실제 이미지 생성](#3-실제-이미지-생성-gemini) 참고).

## 1. 설치와 실행

필요한 프로그램

| 프로그램 | 용도 | 확인 명령 |
|---|---|---|
| Python 3.11 이상 | 백엔드 | `python3 --version` |
| Node.js 20 이상 | 화면(프런트엔드) | `node --version` |
| FFmpeg | 장면 영상과 최종 MP4 만들기 | `ffmpeg -version` |

FFmpeg 설치: macOS `brew install ffmpeg`, Ubuntu `sudo apt install ffmpeg`, Windows `winget install Gyan.FFmpeg`.

### macOS·Linux (한 번에 실행)

```bash
cd projects/006-ai-shorts-studio
./start.sh
```

처음에는 필요한 패키지를 설치하느라 몇 분 걸립니다. "브라우저에서 http://localhost:3000 을 여세요"가 보이면 브라우저로 접속합니다. 끝낼 때는 터미널에서 `Ctrl+C`를 누릅니다.

### Windows (한 번에 실행)

탐색기에서 `projects\006-ai-shorts-studio` 폴더를 열고 **`start-windows.bat`을 더블클릭**합니다.

- 필요한 프로그램(Python, Node.js, FFmpeg)이 있는지 확인하고, 처음에는 패키지를 설치합니다 (몇 분 걸림).
- 백엔드와 화면 서버가 **새 창 두 개**로 열리고, 준비되면 브라우저가 http://localhost:3000 을 엽니다.
- 끝낼 때는 새로 열린 두 창을 닫습니다.
- 영상 자막 글꼴은 자동으로 맑은 고딕(`Malgun Gothic`)을 씁니다.
- 실제 작업은 같은 폴더의 `start-windows.ps1`(PowerShell)이 합니다. 두 파일은 항상 같은 폴더에 두세요. ZIP으로 받았다면 압축을 모두 푼 뒤 실행합니다.
- "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누릅니다 (인터넷에서 받은 파일이라 뜨는 확인창).

### Windows (수동 실행)

PowerShell 창 두 개를 열어 각각 실행합니다.

```powershell
# 창 1: 백엔드
cd projects\006-ai-shorts-studio\backend
py -m venv .venv
.venv\Scripts\python -m pip install -r requirements-dev.txt
.venv\Scripts\python -m uvicorn app.main:app --reload --port 8000
```

```powershell
# 창 2: 화면
cd projects\006-ai-shorts-studio\frontend
npm install
npm run dev
```

브라우저에서 http://localhost:3000 을 엽니다. 영상 자막의 한글이 네모로 보이면 창 1에서 uvicorn 실행 전에 `$env:AISS_SUBTITLE_FONT = "Malgun Gothic"`을 먼저 실행합니다.

## 2. 쇼츠 만들기

프로젝트 화면 위쪽 탭이 작업 순서입니다: **설정 → 대본 → 스토리보드 → 검토 → 렌더링** (작업 탭은 진행 기록)

1. **새 프로젝트** — 첫 화면 왼쪽에서 제목, 주제, 목표 길이(5~180초), 화면 비율(기본 9:16), 분위기/스타일을 넣고 "프로젝트 만들기". 목록에 장면 수·승인 수·최근 렌더 버전이 보입니다.
2. **대본** — "대본 초안 생성 (mock)"으로 예시 대본을 만들거나 직접 씁니다. **빈 줄로 나눈 문단 하나가 장면 하나**가 됩니다. 글자 수·예상 장면 수·읽기 시간이 아래에 보입니다. 다 쓰면 "저장".
3. **스토리보드로 나누기** — 대본 문단이 장면으로 나뉘고, 장면 길이는 글자 수에 맞춰 목표 길이를 나눠 갖습니다.
4. **스토리보드** — 장면마다 대사, 화면 설명, 이미지·영상 프롬프트, 길이를 고치고 "장면 저장". ↑/↓로 순서를 바꾸고 ✕로 지우고 "+ 장면 추가"로 늘립니다. 위쪽에 합계 길이와 목표와의 차이가 보입니다.
5. **검토** — 장면마다 "이미지 생성" 또는 "영상 생성"을 누르고, 결과를 보고 **승인** 또는 **반려(사유 필수)** 합니다.
   - 반려한 장면은 스토리보드에서 프롬프트를 고친 뒤 다시 생성합니다. 이전 결과는 v1, v2…로 남습니다.
   - 실패하면 오류와 "재시도" 버튼이 보입니다.
   - 승인한 장면의 내용을 고치면 다시 "검토 필요"가 됩니다.
6. **렌더링**
   - 위쪽 목록에 아직 남은 일(승인 안 된 장면, 음성 없는 장면 등)이 보입니다. 목록이 비어야 렌더링할 수 있습니다.
   - "음성 만들기"로 대사 음성을 만듭니다. 대사를 고치면 그 장면 음성은 "대사 바뀜"이 되어 다시 만들어야 합니다.
   - 자막은 대사와 장면 길이로 자동 계산됩니다. "SRT 내려받기"로 따로 받을 수 있습니다.
   - "음성 넣기", "자막을 영상에 입히기"를 고른 뒤 "MP4 렌더링". 끝나면 아래에 영상이 나오고 **"MP4 내려받기"** 로 `프로젝트명_v1.mp4`를 받습니다.
7. **작업** — 모든 생성·렌더링 작업의 상태, 시도 횟수, 걸린 시간, 비용(mock은 무료), 오류를 봅니다. 실패한 작업은 여기서도 재시도할 수 있습니다.

## 3. 실제 이미지 생성 (Gemini)

기본은 mock이라 "MOCK IMAGE"만 나옵니다. Google AI Pro 요금제의 **월 $10 Google Cloud 크레딧**으로 실제 이미지를 만들 수 있습니다. (Flow·Whisk용 "AI 크레딧"은 API에 쓸 수 없습니다.)

1. **크레딧 활성화**: https://developers.google.com/profile 에 Pro 요금제 계정으로 로그인 → Google Developer Program 혜택에서 Google Cloud 크레딧을 활성화하고 크레딧을 받을 Google Cloud 프로젝트를 고릅니다. (자동으로 켜지지 않습니다. 매달 초기화되고 이월되지 않습니다.)
2. **결제 계정·예산 알림**: Google Cloud 콘솔에서 그 프로젝트에 결제 계정이 연결되어 있는지 확인하고, **예산 및 알림**에서 예: $5 알림을 만들어 둡니다. 크레딧을 넘게 쓰면 카드로 청구될 수 있습니다.
3. **API 키 발급**: https://aistudio.google.com 의 "Get API key"에서 **1번에서 고른 프로젝트**로 키를 만듭니다.
4. **.env 만들기**: `projects/006-ai-shorts-studio` 폴더의 `.env.example`을 복사해 이름을 `.env`로 바꾸고 아래 두 줄을 넣습니다. (메모장으로 열어도 됩니다. 키는 다른 곳에 붙여넣거나 공유하지 마세요.)
   ```
   AISS_IMAGE_PROVIDER=gemini
   GEMINI_API_KEY=발급받은키
   ```
5. **다시 실행**: 열려 있는 서버 창을 닫고 `start-windows.bat`(또는 `./start.sh`)을 다시 실행합니다.
6. **확인**: 검토 탭 위쪽에 "이미지 gemini (유료)"가 보입니다. "이미지 생성"을 누르면 예상 비용 확인창이 뜨고, 확인하면 실제 이미지가 만들어집니다. 쓴 금액(예상치)은 작업 탭에 쌓입니다.

- 비용 참고: 기본 모델(gemini-3.1-flash-image) 1장 약 $0.067 → 장면 4개 1회 약 $0.27. $10이면 대략 150장. 정확한 금액은 Google Cloud 결제 화면에서 확인합니다.
- 더 싼 모델을 쓰려면 `.env`에 `AISS_GEMINI_IMAGE_MODEL=gemini-3.1-flash-lite-image`를 추가해 보세요 (약 $0.034, 계정에서 사용 가능한지 확인 필요). 모델을 찾을 수 없다는 오류가 나면 이 줄을 지웁니다.
- 프롬프트 끝의 `--ar 9:16 --style raw` 같은 Midjourney 옵션은 자동으로 지우고, 화면 비율은 프로젝트 설정(9:16)으로 보냅니다.
- 실패하면 작업이 "실패"로 표시되고 이유가 한국어로 나옵니다. 고친 뒤 "재시도"를 누르세요. 재시도도 비용 확인창을 거칩니다.
- 다시 mock으로 돌아가려면 `.env`에서 `AISS_IMAGE_PROVIDER=gemini` 줄 앞에 `#`을 붙이고 다시 실행합니다.

### 실제 영상 생성 (Veo)

같은 Gemini 키로 Veo 영상도 만들 수 있습니다. **이미지보다 훨씬 비쌉니다.**

1. `.env`에 한 줄을 추가하고 서버를 다시 실행합니다.
   ```
   AISS_VIDEO_PROVIDER=gemini
   ```
   PowerShell이라면: `Add-Content -Path .env -Encoding ascii -Value "AISS_VIDEO_PROVIDER=gemini"`
2. 검토 탭 위쪽에 "영상 gemini (유료)"가 보이면 준비된 것입니다.
3. **먼저 장면 이미지를 만들고 승인한 뒤** "영상 생성"을 누르세요. 그 이미지를 첫 화면으로 움직이는 영상을 만듭니다 (영상 프롬프트 사용).
4. 1~6분 정도 걸립니다. 그동안 카드에 "생성 중…"이 보입니다. 창을 닫지 마세요.

- 비용 참고 (기본 Veo 3.1 Lite, 720p, 소리 포함 요금): 초당 약 $0.05 → 8초 영상 1개 약 $0.40. 장면 4개면 약 $1.6. $10 크레딧으로 영상 20~25개 정도입니다.
- Veo 영상은 **4·6·8초**만 만들 수 있습니다. 장면 길이가 8초보다 길면 8초짜리가 만들어지고, 최종 영상에서는 나머지 시간 동안 마지막 화면이 멈춰 보입니다. 자연스럽게 하려면 스토리보드에서 장면을 8초 이하로 나누세요 (예: 15초 장면 → 8초 + 7초).
- 품질을 올리려면 `.env`에 `AISS_GEMINI_VIDEO_MODEL=veo-3.1-fast-generate-preview`를 추가합니다 (약 2배 가격).
- 20분이 지나도 끝나지 않으면 실패로 표시됩니다. 이때 재시도하면 새로 만들어지고 비용이 다시 듭니다.

## 4. 알아 두면 좋은 점

- 데이터와 만든 파일은 `projects/006-ai-shorts-studio/storage/`에 저장됩니다. 이 폴더를 지우면 모든 프로젝트가 사라집니다. (Git에는 올라가지 않습니다)
- 작업이 진행 중일 때는 화면이 1.5초마다 자동으로 새로 고쳐집니다. 진행 중에는 같은 장면을 다시 생성하거나 지울 수 없습니다.
- 저장하지 않은 변경이 있으면 "저장 안 됨"이 보이고, 프로젝트 탭이나 "← 목록"으로 옮기거나 새로고침·창 닫기를 할 때 확인창이 뜹니다.
- 결과 MP4는 H.264 영상이라 Chrome·Edge·Safari 등 일반 브라우저와 휴대폰에서 재생됩니다.

## 5. 문제가 생겼을 때

| 증상 | 확인할 것 |
|---|---|
| "백엔드(http://localhost:8000)에 연결할 수 없습니다" | 백엔드 창이 켜져 있는지 확인하고, "다시 시도"를 누릅니다. |
| 영상 생성·렌더링이 "FFmpeg를 찾을 수 없습니다"로 실패 | FFmpeg를 설치하거나, 설치 위치를 `AISS_FFMPEG_PATH` 환경 변수로 알려 줍니다. |
| 영상에 입힌 자막 글자가 네모(□)로 보임 | 한글 글꼴을 찾지 못한 경우입니다. `AISS_SUBTITLE_FONT=Malgun Gothic`(Windows), `Apple SD Gothic Neo`(macOS), `Noto Sans CJK KR`(Linux)처럼 지정하고 백엔드를 다시 켭니다. 또는 "자막을 영상에 입히기"를 끄면 플레이어에서 켜는 자막 트랙만 들어갑니다. |
| "렌더링" 버튼이 꺼져 있음 | 위쪽 빨간 목록에 남은 일이 적혀 있습니다. 보통 승인 안 된 장면이나 음성이 없는 장면입니다. |
| 작업이 "서버가 다시 시작되어 작업이 중단되었습니다"로 실패 | 생성 도중 백엔드가 꺼졌던 경우입니다. "재시도"를 누르면 됩니다. |
| 이미지 생성이 "GEMINI_API_KEY가 없습니다"로 실패 | `.env` 파일 이름과 위치(`projects/006-ai-shorts-studio/.env`)를 확인하고 서버를 다시 실행하세요. 메모장이 `.env.txt`로 저장하지 않았는지도 확인하세요. |
| "키가 올바르지 않거나 권한이 없습니다 (403)" | 키를 다시 복사해 넣고, 그 키의 프로젝트에 결제 계정이 연결되어 있는지 확인하세요. |
| "모델을 찾을 수 없습니다 (404)" | `AISS_GEMINI_IMAGE_MODEL` 줄을 지워 기본 모델로 되돌리세요. |
| "사용량 한도를 넘었습니다 (429)" | 잠시 뒤 재시도하세요. 계속되면 Google Cloud의 할당량·결제 상태를 확인하세요. |
| "안전 필터로 이미지가 만들어지지 않았습니다" | 프롬프트 표현을 바꿔 다시 생성하세요. |
| "Veo 영상 생성 실패" / "Veo 안전 필터" | 메시지 내용을 확인하고 영상 프롬프트를 바꿔 재시도하세요. 실존 인물처럼 보이는 얼굴은 거절될 수 있습니다. |
| 포트가 이미 사용 중 | 다른 프로그램이 8000·3000번을 쓰고 있습니다. 그 프로그램을 끄는 것이 가장 간단합니다. 다른 포트를 쓰려면 수동 실행에서 `--port`(백엔드)와 `-p`(화면)를 바꾸고, `frontend/.env.local`의 `NEXT_PUBLIC_API_BASE`와 백엔드의 `AISS_CORS_ORIGINS`도 같은 주소로 맞춥니다. |
