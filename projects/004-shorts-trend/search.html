🔎 쇼츠 직접 검색

내 API 키로 국가·기간·분야를 골라 바로 분석해요. 최근 쇼츠를 시간당 조회수로 줄 세우고 키워드를 뽑습니다.

API 키는 Google Cloud 콘솔에서 YouTube Data API v3를 켜고 사용자 인증 정보 → API 키로 무료 발급합니다. 하루 기본 10,000단위라 한 번 분석(100개)에 약 200단위가 듭니다.

📈 급상승 키워드

여러 떡상 쇼츠에 함께 나온 해시태그·제목 단어 순위입니다. 누르면 해당 영상만 봅니다.
