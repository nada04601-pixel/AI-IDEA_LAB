- 관련 아이디어: [005 오늘의 떡상 쇼츠 분석기](../005-shorts-trend/idea.md), [006 AI Shorts Studio](../006-ai-shorts-studio/idea.md)

## 1. 목표

한국 1960~1980년대 정겨운 생활 풍경을 따뜻한 동화책풍 그림으로 표현하고, 다른 그림 찾기 문제 이미지 생성부터 세로형 Shorts 영상 제작, 검수, YouTube 업로드까지 최대한 자동화하는 저비용 시스템. 초기 목표는 **하루 1~3개를 안정적으로** 만드는 것.

## 2. 핵심 원칙

- 무료·오픈소스 우선. 유료 API는 필수/선택과 예상 비용을 구분.
- YouTube 업로드는 **기본 비공개**. 사용자가 공개 게시를 명시적으로 켜기 전에는 자동 공개 금지.
- 모든 영상은 업로드 전 자동 품질 검사를 통과해야 하며, 실패 시 업로드하지 않고 로그를 남긴다.
- 참고 채널의 영상·이미지·캐릭터를 복제하지 않고 독자적인 한국 레트로 풍경을 만든다.
- 하드웨어 사양이 불명확하면 로컬 이미지 생성 없이 테스트 가능한 기본 버전을 먼저 완성하고, 이미지 생성은 플러그인으로 추가.

## 3. 채널 콘셉트

- 가칭: 「그리운 옛날 풍경」 / 「추억의 다른 그림 찾기」
- 시청자: 옛날 한국 생활 풍경을 좋아하는 중장년·어르신
- 형식: 세로형 Shorts, 25~40초
- 첫 시리즈: 고향 마을, 옛날 부엌, 시골 장터, 비 오는 흙길, 동네 구멍가게
- 톤: 따뜻하고 차분함. 과도한 번쩍임·빠른 전환·큰 음량 변화 금지

## 4. 시각 디자인

- 옛 동화책풍 손그림·수채화 배경. 따뜻한 베이지, 흙빛 갈색, 연두, 옅은 주황.
- 배경: 기와집, 돌담, 장독대, 감나무, 우물, 흙길, 평상, 빨랫줄, 구멍가게, 시장
- 소품: 고무신, 양은 냄비, 놋그릇, 바구니, 빗자루, 자전거, 저울, 옛 간판
- 무관한 나라의 전통 건축·소품이 섞이지 않게. 두 그림의 크기·구도 동일. 작은 디테일보다 한눈에 보이는 차이.
- 큰 한글 글꼴, 높은 대비.

## 5. 콘텐츠 규칙

- 차이 기본 5개, 난이도에 따라 3개/7개.
- 차이 유형: 물체 추가·제거, 색상·모양·무늬·방향 변경.
- 두 그림은 같은 장면 기반(따로 두 번 생성 금지). 정답 좌표·유형을 JSON으로 저장하고 정답 화면은 이 데이터로 만든다.
- 의미 있는 물체·영역만 차이로. 정답끼리 겹치거나 너무 가깝지 않게, 정답 원이 차이를 정확히 감싸게.

타임라인: 오프닝 0~3초 → 문제 3~23초(20초 카운트다운) → 정답 공개 23~33초 → 마무리 33~36초("몇 개나 찾으셨나요? 다음 추억 여행에서 만나요!")

## 6. 파이프라인

주제 선택 → 원본 장면 생성 → 장면 구성(레이어·객체 단위) → 차이 생성(정답 JSON) → 품질 검사 → FFmpeg 렌더링(1080×1920) → 메타데이터 → 최종 검수 → YouTube 비공개 업로드(OAuth) → 성과 기록(SQLite/CSV)

## 7. 품질 검사·실패 처리

- 정답 개수 불일치, 원본·수정본 크기·비율 불일치 → 실패
- 정답 원이 차이를 벗어나거나 원끼리 겹치거나 차이가 너무 작음 → 검수 대상
- 영상 1080×1920·길이·코덱·크기 확인
- 외부 작업 오류는 재시도 횟수 제한 + 오류 로그
- 같은 작업 ID·같은 영상 중복 업로드 금지
- 음악·글꼴·모델·참고 자료의 이용 약관과 상업적 이용 조건 확인

## 8. 단계별 구현

| Phase 2 | 샘플 10개로 정답 개수·좌표·가독성·렌더링 검사, 실패 로그 확인 | ✅ 완료 (10개 중 10개 ready) |
