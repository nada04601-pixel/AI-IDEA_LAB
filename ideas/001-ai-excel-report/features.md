# 001. AI Excel 보고서 자동생성기

# 기능정의서

> 기준 문서: `idea.md`, `requirements.md`
> 상태 표기: 대기 / 진행 / 완료
> `(가정)` 표시는 문서에 없어서 임시로 정한 값입니다. 확인 후 수정하세요.

---

## 0. 공통 원칙

모든 기능은 아래 원칙을 따른다.

1. **AI는 "컬럼 의미 분석과 매핑 추천"에만 사용한다.** 합계, 집계, 날짜 변환, 셀 입력은 AI가 아니라 코드가 결정론적으로 처리한다. (정확성, 비용, 재현성 확보)
2. **AI에는 전체 데이터를 보내지 않는다.** 컬럼명, 데이터 타입, 소량의 샘플 값만 전달한다. (고객 데이터 보호)
3. **AI 결과는 항상 사용자가 확인한다.** 매핑을 자동으로 확정해서 보고서를 만들지 않는다.
4. **원본 파일은 수정하지 않는다.** 정규화와 가공은 복사본에서만 수행한다.
5. **같은 입력과 같은 매핑이면 같은 결과가 나와야 한다.**

## 1. 전체 사용자 흐름

`idea.md`는 컬럼 매핑(5번)이 템플릿 선택(8번)보다 앞에 있는데, 매핑은 "보고서에 필요한 컬럼"이 정해져야 가능하다. 그래서 **템플릿 선택을 매핑 앞으로** 옮겼다.

```
[F-001 파일 업로드]
      ↓
[F-002 보고서 템플릿 선택]
      ↓
[F-003 데이터 분석] → [F-004 AI 컬럼 매핑] → [F-005 매핑 확인/수정]
      ↓
[F-006 데이터 정규화] → [F-007 집계/가공]
      ↓
[F-008 보고서 생성] → [F-009 미리보기] → [F-010 다운로드]
      ↓
[F-011 작업 이력 저장/조회]

(공통) [F-012 사용자 인증]
```

## F-001 파일 업로드

- **목적**: 분석할 원본 데이터를 시스템에 올린다.
- **사용자 시나리오**: 사용자가 Excel 또는 CSV 파일을 드래그하거나 선택해서 업로드한다.
- **기능 요구사항**
  - 지원 형식: `.xlsx`, `.csv` (`.xls`는 MVP 제외)
  - 한 번에 파일 1개 업로드 (다중 파일 취합은 범위 밖)
  - 파일 크기 제한 10MB, 최대 50,000행 (가정)
  - Excel에 시트가 여러 개면 사용자가 시트를 선택한다.
  - CSV는 인코딩(UTF-8, CP949)을 자동 감지한다. 한국 회사 CSV는 CP949가 흔하다.
  - 업로드 완료 후 파일명, 시트명, 행 수를 보여준다.
- **인수 조건**
  - [ ] `.xlsx`와 `.csv` 업로드가 성공한다.
  - [ ] CP949로 저장된 CSV의 한글이 깨지지 않는다.
  - [ ] 시트가 2개 이상인 파일은 시트 선택 화면이 나온다.
  - [ ] 제한을 넘는 파일은 업로드 전에 사유와 함께 거부된다.
- **예외/에러 케이스**
  - 지원하지 않는 확장자, 확장자만 바꾼 가짜 파일
  - 비밀번호가 걸린 Excel, 손상된 파일
  - 데이터가 0행이거나 헤더만 있는 파일
- **데이터**: 파일 메타(파일명, 크기, 형식, 업로드 일시, 사용자 ID), 저장 위치
- **범위 밖**: 여러 파일 동시 취합, `.xls`, 구글 시트 연동, 드라이브 연동
- **상태**: 대기

## F-002 보고서 템플릿 선택

- **목적**: 결과물의 목표 양식을 정한다. 매핑의 기준이 되는 "필요한 컬럼" 목록이 여기서 결정된다.
- **사용자 시나리오**: 사용자가 템플릿 목록에서 보고서 양식 하나를 선택한다.
- **기능 요구사항**
  - 템플릿은 **개발자가 사전 등록**한다. (사용자가 임의의 양식을 올리는 기능은 범위 밖)
  - 템플릿 하나는 다음을 정의한다.
    - 템플릿 Excel 파일 (서식, 시트 구성)
    - 필요 필드 목록 (필드명, 데이터 타입, 필수 여부)
    - 집계 규칙 (예: 거래처별 매출 합계)
    - 데이터가 들어갈 시트와 셀 위치
  - 템플릿 선택 시 필요 필드 목록을 미리 보여준다.
  - MVP 초기 템플릿은 `idea.md` 예시 기준 **"거래처별/상태별 매출 보고서"** 1종으로 시작한다.
- **인수 조건**
  - [ ] 등록된 템플릿 목록이 조회된다.
  - [ ] 템플릿을 선택하면 필요 필드 목록이 표시된다.
  - [ ] 템플릿을 선택하지 않으면 다음 단계로 넘어갈 수 없다.
- **예외/에러 케이스**: 등록된 템플릿이 없는 경우, 템플릿 파일 자체가 손상된 경우
- **데이터**: 템플릿 메타, 필드 정의, 집계 규칙, 셀 매핑 정보
- **범위 밖**: 사용자 템플릿 업로드, 템플릿 편집기, 템플릿 마켓
- **상태**: 대기

## F-003 데이터 분석

- **목적**: 업로드된 데이터의 구조를 파악해 매핑과 정규화의 근거 정보를 만든다.
- **사용자 시나리오**: 업로드 직후 시스템이 자동으로 컬럼 구조를 분석하고 결과를 요약해서 보여준다.
- **기능 요구사항**
  - 헤더 행을 감지한다. 제목 행이 위에 있는 파일도 고려한다. (감지 실패 시 사용자가 헤더 행 번호를 지정)
  - 컬럼별로 다음을 산출한다.
    - 컬럼명, 추정 데이터 타입(문자/숫자/날짜), 빈 값 비율, 고유값 개수
    - 샘플 값 5개
  - 병합 셀, 완전히 빈 행/열은 감지해서 경고한다.
  - 분석 결과를 표로 보여준다.
- **인수 조건**
  - [ ] `idea.md` 예시 데이터(7개 컬럼)에서 각 컬럼의 타입이 올바르게 추정된다.
  - [ ] `2026-09-01`, `2026.09.02`, `2026/09/03`이 섞인 컬럼이 "날짜"로 추정된다.
  - [ ] 헤더 행이 첫 줄이 아닌 파일에서 헤더 행을 지정할 수 있다.
- **예외/에러 케이스**: 컬럼명 중복, 컬럼명이 비어 있음, 숫자와 문자가 섞인 컬럼
- **데이터**: 컬럼 프로파일(이름, 타입, 빈 값 비율, 샘플)
- **범위 밖**: 이상치 탐지, 통계 시각화
- **상태**: 대기

## F-004 AI 컬럼 매핑

- **목적**: 원본 컬럼과 템플릿 필요 필드를 AI가 의미 기준으로 연결해 추천한다.
- **사용자 시나리오**: 분석 직후 시스템이 "거래처 → 고객사"처럼 매핑안을 자동으로 제시한다.
- **기능 요구사항**
  - AI 입력은 **컬럼명 + 타입 + 샘플 값(소량)** 과 **템플릿 필드 정의**로 한정한다. (공통 원칙 2)
  - AI 출력은 구조화된 JSON으로 받는다: 필드별 `원본 컬럼`, `신뢰도(높음/중간/낮음)`, `근거 한 줄`
  - 확신이 낮거나 대응 컬럼이 없으면 **억지로 매핑하지 않고 "미매핑"** 으로 둔다.
  - 한 원본 컬럼이 여러 필드에 중복 매핑되지 않도록 검증한다.
  - AI 응답이 JSON 형식이 아니거나 호출이 실패하면 **이름 유사도 기반 규칙 매핑**으로 대체한다.
- **인수 조건**
  - [ ] `idea.md` 예시 7개 컬럼이 템플릿 필드에 의도한 대로 매핑된다.
  - [ ] 대응 컬럼이 없는 필수 필드는 "미매핑"으로 표시된다.
  - [ ] AI 호출 실패 시에도 규칙 매핑 결과가 화면에 나온다.
  - [ ] 전체 행 데이터가 AI로 전송되지 않는다. (요청 페이로드 확인)
- **예외/에러 케이스**: AI 타임아웃, 응답 형식 오류, 컬럼명이 `Column1`, `A`처럼 의미 없는 경우
- **데이터**: 매핑안(필드 ID, 원본 컬럼, 신뢰도, 근거, 생성 방식: AI/규칙)
- **범위 밖**: 컬럼을 합치거나 쪼개는 변환 매핑(예: 성+이름 → 이름), 이전 매핑 학습
- **상태**: 대기

## F-005 매핑 확인/수정

- **목적**: AI 추천을 사용자가 검증하고 확정한다. (공통 원칙 3)
- **사용자 시나리오**: 사용자가 매핑 표를 보고 틀린 항목을 드롭다운으로 바꾼 뒤 "확정"을 누른다.
- **기능 요구사항**
  - 필드별로 `원본 컬럼`, `신뢰도`, `샘플 값`을 나란히 보여준다.
  - 원본 컬럼을 드롭다운으로 변경하거나 "사용 안 함"으로 지정할 수 있다.
  - 신뢰도 "낮음"과 "미매핑" 항목을 시각적으로 강조한다.
  - 필수 필드가 미매핑이면 확정할 수 없다.
  - 확정된 매핑을 기억해 **같은 템플릿으로 다시 올릴 때 기본값으로 제안**한다. (P1)
- **인수 조건**
  - [ ] 매핑 변경 시 샘플 값이 즉시 갱신된다.
  - [ ] 필수 필드가 미매핑이면 "확정" 버튼이 비활성화되고 이유가 표시된다.
  - [ ] 같은 원본 컬럼을 두 필드에 지정하면 경고가 나온다.
  - [ ] 확정된 매핑이 작업 이력에 저장된다.
- **예외/에러 케이스**: 매핑 확정 후 뒤로 가서 파일을 바꾸는 경우 (매핑 초기화 안내)
- **데이터**: 확정 매핑(필드 ID, 원본 컬럼, 수정 여부)
- **범위 밖**: 사용자 정의 필드 추가, 수식 매핑
- **상태**: 대기

## F-006 데이터 정규화

- **목적**: 형식이 제각각인 값을 보고서에 쓸 수 있게 통일한다.
- **사용자 시나리오**: 매핑 확정 후 시스템이 날짜, 금액, 거래처명을 정리하고 변경 내역을 보여준다.
- **기능 요구사항**
  - **날짜**: `2026-09-01`, `2026.09.02`, `2026/09/03`, Excel 날짜 시리얼 값을 모두 `YYYY-MM-DD`로 통일한다. 해석 불가한 값은 오류 목록에 담는다.
  - **금액**: 쉼표, 통화 기호, "원" 문자를 제거하고 숫자로 변환한다. 변환 불가한 값은 오류 목록에 담는다.
  - **거래처명**: `(주)`, `㈜`, `주식회사`, 앞뒤 공백, 중복 공백을 제거한 기준 이름을 만든다. (예: `(주)대한상사`, `대한상사` → `대한상사`)
  - 거래처명 통합은 **자동 확정하지 않고** "이 이름들을 같은 거래처로 묶을까요?"라고 사용자에게 제안한다. 서로 다른 회사가 합쳐지는 사고를 막기 위해서다.
  - 정규화 결과 요약을 보여준다: 변환 N건, 오류 N건, 통합 제안 N건
- **인수 조건**
  - [ ] `idea.md` 예시의 날짜 3종이 모두 `YYYY-MM-DD`로 변환된다.
  - [ ] `(주)대한상사`와 `대한상사`가 통합 제안 목록에 나타난다.
  - [ ] 변환 실패 행이 행 번호와 함께 표시된다.
  - [ ] 오류 행은 사용자가 "제외하고 진행"을 선택할 수 있다.
  - [ ] 원본 파일과 원본 값은 변경되지 않는다.
- **예외/에러 케이스**: 날짜가 `2026-13-45`처럼 불가능한 값, 금액이 음수 또는 빈 값, 거래처명이 비어 있음
- **데이터**: 정규화 결과, 오류 행 목록(행 번호, 컬럼, 사유), 통합 규칙
- **범위 밖**: 유사 거래처명 AI 추정 통합, 주소·전화번호 정규화, 외화 환산
- **상태**: 대기

## F-007 데이터 집계/가공

- **목적**: 템플릿의 집계 규칙에 따라 정규화된 데이터를 계산한다.
- **사용자 시나리오**: 시스템이 거래처별, 상태별 매출 합계 등을 자동으로 계산한다.
- **기능 요구사항**
  - 집계는 **코드로 처리**한다. (공통 원칙 1)
  - MVP 지원 연산: 합계, 건수, 평균, 그룹별 집계 (거래처별, 상태별, 부서별, 월별)
  - 기본 템플릿 산출물
    - 거래처별 매출 합계
    - 상태별 매출 합계 및 건수
    - 전체 합계
  - 필터(기간, 상태)는 MVP 제외, 필요 시 후속 단계에서 추가한다.
  - **검증**: 집계 결과의 전체 합계가 정규화된 원본 금액의 총합과 일치하는지 확인한다.
- **인수 조건**
  - [ ] `idea.md` 예시 3행에서 거래처별, 상태별 합계가 수기 계산 결과와 일치한다.
  - [ ] 그룹별 합계의 총합이 전체 합계와 일치한다.
  - [ ] 같은 입력으로 여러 번 실행해도 결과가 동일하다.
  - [ ] 오류로 제외된 행 수가 결과 요약에 표시된다.
- **예외/에러 케이스**: 집계 대상 행이 0건, 금액 컬럼이 전부 오류
- **데이터**: 집계 결과 테이블
- **범위 밖**: 사용자 정의 수식, 피벗 편집, 전년 대비 증감 등 파생 지표
- **상태**: 대기

## F-008 Excel 보고서 생성

- **목적**: 집계 결과를 템플릿 양식 그대로 채운 Excel 파일을 만든다.
- **사용자 시나리오**: 사용자가 "보고서 생성"을 누르면 템플릿에 데이터가 입력된 파일이 만들어진다.
- **기능 요구사항**
  - 템플릿 파일을 복사한 뒤 지정된 시트, 셀 위치에 값을 입력한다.
  - 템플릿의 서식(폰트, 색상, 테두리, 열 너비, 숫자/날짜 형식)을 유지한다.
  - 데이터 행 수가 가변인 영역은 행을 확장해서 입력한다.
  - 합계 등은 **값으로 입력**하되, 가능하면 Excel 수식도 함께 유지한다. (확인 필요)
  - 생성 파일명 규칙: `{템플릿명}_{YYYYMMDD_HHmm}.xlsx`
  - 생성 시간이 길어지면 진행 상태를 표시한다.
- **인수 조건**
  - [ ] 생성된 파일이 Excel에서 오류 없이 열린다.
  - [ ] 템플릿의 서식이 깨지지 않는다.
  - [ ] 데이터 행이 템플릿 기본 행 수보다 많아도 정상 입력된다.
  - [ ] 생성 파일의 합계가 F-007 결과와 일치한다.
- **예외/에러 케이스**: 템플릿의 셀 위치가 잘못 정의된 경우, 시트 보호가 걸린 템플릿
- **데이터**: 생성 파일 메타(경로, 크기, 생성 일시)
- **범위 밖**: 차트 자동 생성, 다중 시트 동적 생성, PDF 출력
- **상태**: 대기

## F-009 결과 미리보기

- **목적**: 다운로드 전에 결과를 눈으로 확인한다.
- **사용자 시나리오**: 생성 직후 화면에서 보고서 내용을 표로 확인한다.
- **기능 요구사항**
  - 생성된 보고서의 시트별 내용을 웹 표로 보여준다. (서식 완벽 재현은 목표가 아님)
  - 시트가 여러 개면 탭으로 전환한다.
  - 대용량은 상위 100행만 보여주고 "전체는 다운로드해서 확인"을 안내한다.
  - 미리보기 화면에 합계, 처리 건수, 제외된 오류 행 수를 요약으로 표시한다.
- **인수 조건**
  - [ ] 미리보기의 합계와 생성 파일의 합계가 일치한다.
  - [ ] 시트 탭 전환이 동작한다.
- **예외/에러 케이스**: 미리보기 변환 실패 시에도 다운로드는 가능해야 한다.
- **데이터**: 없음 (생성 파일에서 읽음)
- **범위 밖**: 미리보기에서 값 직접 수정, 서식 100% 재현
- **상태**: 대기

## F-010 Excel 다운로드

- **목적**: 완성된 보고서를 사용자 PC로 내려받는다.
- **사용자 시나리오**: 미리보기 확인 후 "다운로드"를 누른다.
- **기능 요구사항**
  - `.xlsx` 파일을 F-008의 파일명 규칙으로 내려준다.
  - 작업 이력에서도 과거 결과 파일을 다시 내려받을 수 있다.
  - 본인이 만든 파일만 다운로드할 수 있다. (권한 검증)
  - 생성된 파일의 보관 기간은 30일 (가정). 이후 파일은 삭제하고 이력 메타만 남긴다.
- **인수 조건**
  - [ ] 다운로드한 파일이 Excel에서 정상적으로 열린다.
  - [ ] 다른 사용자의 파일 URL로 접근하면 거부된다.
  - [ ] 보관 기간이 지난 파일은 "만료됨"으로 표시된다.
- **예외/에러 케이스**: 파일이 이미 삭제된 경우, 다운로드 중 네트워크 오류
- **데이터**: 다운로드 일시 (이력에 기록)
- **범위 밖**: 이메일 발송, 공유 링크, 클라우드 저장소 업로드
- **상태**: 대기

## F-011 작업 이력 조회

- **목적**: 지난 작업을 확인하고 결과를 다시 받거나 같은 설정으로 재실행한다.
- **사용자 시나리오**: 사용자가 이력 화면에서 과거 보고서 목록을 보고 다시 다운로드한다.
- **기능 요구사항**
  - 이력 항목: 작업 일시, 원본 파일명, 템플릿명, 처리 행 수, 오류 행 수, 상태(성공/실패)
  - 최신순 목록, 페이지네이션
  - 상세 화면에서 사용한 **확정 매핑**과 오류 요약을 볼 수 있다.
  - 결과 파일 다운로드 (F-010 연결)
  - "같은 매핑으로 새 파일 올리기" (P1): 이력의 매핑을 다음 작업의 기본값으로 불러온다. 매주 같은 보고서를 만드는 사용자에게 가장 가치가 큰 기능이다.
  - 이력 삭제 기능
- **인수 조건**
  - [ ] 보고서 생성이 끝나면 이력이 자동으로 한 건 쌓인다.
  - [ ] 실패한 작업도 사유와 함께 이력에 남는다.
  - [ ] 사용자는 본인 이력만 볼 수 있다.
  - [ ] 이력 삭제 시 연결된 파일도 함께 삭제된다.
- **예외/에러 케이스**: 이력이 없는 경우의 빈 화면, 만료된 파일
- **데이터**: 작업 이력(ID, 사용자, 원본 파일명, 템플릿, 매핑 스냅샷, 결과 파일 경로, 통계, 상태, 일시)
- **범위 밖**: 이력 검색·필터 고도화, 작업 예약/자동 실행, 팀 단위 이력 공유
- **상태**: 대기

## F-012 사용자 인증

- **목적**: 작업 이력과 파일을 사용자별로 분리한다. 요구사항 문서에 명시되어 있지 않지만, 이력 저장(F-011)의 전제 조건이다.
- **사용자 시나리오**: 사용자가 가입 후 로그인해서 서비스를 사용한다.
- **기능 요구사항**
  - 이메일 + 비밀번호 가입/로그인 (소셜 로그인은 후순위)
  - 비밀번호는 해시로 저장한다.
  - 로그인하지 않은 사용자는 모든 기능 접근이 차단된다.
  - 세션 만료 시 재로그인 안내
- **인수 조건**
  - [ ] 가입, 로그인, 로그아웃이 동작한다.
  - [ ] 비로그인 상태로 업로드, 이력, 다운로드 URL에 접근하면 차단된다.
- **예외/에러 케이스**: 중복 이메일, 잘못된 비밀번호 반복 시도
- **데이터**: 사용자(ID, 이메일, 비밀번호 해시, 가입일)
- **범위 밖**: 팀/조직 관리, 권한 등급, 결제 연동, 소셜 로그인
- **상태**: 대기
