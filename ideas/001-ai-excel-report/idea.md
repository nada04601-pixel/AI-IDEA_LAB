# 001. AI Excel 보고서 자동생성기

## 1. 아이디어 개요

### 아이디어명
AI Excel 보고서 자동생성기

### 한 줄 설명
사용자가 Excel 또는 CSV 데이터를 업로드하면 AI가 데이터를 분석하고 필요한 항목을 자동으로 매핑하여 회사에서 사용하는 보고서 형태의 Excel 파일을 자동으로 생성해주는 서비스.

---

## 2. 해결하려는 문제

회사에서는 매일 또는 매주 반복적으로 Excel 데이터를 정리하고 보고서를 작성하는 업무가 발생한다.

특히 다음과 같은 반복 작업이 많다.

- 여러 Excel 파일의 데이터 취합
- 컬럼명 및 데이터 형식 정리
- 날짜 형식 통일
- 거래처명 및 회사명 정리
- 필요한 데이터만 추출
- 합계 및 집계
- 기존 Excel 보고서 양식에 데이터 입력
- 반복적인 보고서 생성

이러한 작업은 단순 반복 작업이지만 많은 시간이 소요되며,
담당자가 수작업으로 처리하는 과정에서 오류가 발생할 수 있다.

---

## 3. 해결 방법

사용자가 Excel 또는 CSV 파일을 업로드하면 시스템이 다음 과정을 자동으로 수행한다.

1. 파일 업로드
2. Excel/CSV 데이터 분석
3. 컬럼 구조 분석
4. AI를 이용한 컬럼 의미 분석
5. 보고서 컬럼과 원본 데이터 컬럼 자동 매핑
6. 사용자 매핑 결과 확인 및 수정
7. 데이터 형식 정규화
8. 보고서 템플릿 선택
9. 데이터 집계 및 가공
10. Excel 보고서 생성
11. 생성된 보고서 미리보기
12. Excel 파일 다운로드
13. 작업 이력 저장

---

## 4. 핵심 가치

### 사용자 입장

반복적인 Excel 보고서 작성 시간을 줄일 수 있다.

### 서비스 입장

단순한 AI 챗봇이 아니라 실제 업무 결과물을 만들어주는
업무 자동화 서비스로 발전시킨다.

### 장기 목표

처음에는 특정 회사의 Excel 보고서 자동화 프로그램으로 개발하고,

이후 다양한 회사와 업무에 적용할 수 있는
범용적인 AI Excel 자동화 SaaS로 발전시킨다.

## 7. 사용 예시

### 입력

사용자가 다음과 같은 Excel 파일을 업로드한다.

| 거래처 | 매출일 | 금액 | 담당자 | 부서 | 상품 | 상태 |
|---|---|---:|---|---|---|---|
| (주)대한상사 | 2026-09-01 | 1000000 | 홍길동 | 영업1팀 | A상품 | 완료 |
| 대한상사 | 2026.09.02 | 1360000 | 김철수 | 영업1팀 | B상품 | 완료 |
| ABC테크 | 2026/09/03 | 850000 | 이영희 | 영업2팀 | A상품 | 진행 |

---

### AI 분석

AI가 데이터의 의미를 분석한다.

예:

```text
거래처 → 고객사
매출일 → 거래일자
금액 → 매출금액
담당자 → 담당자
부서 → 부서
상품 → 상품명
상태 → 처리상태

## 8. 출력 결과

사용자가 업로드한 데이터를 분석한 후,
회사에서 사용하는 Excel 보고서 양식에 맞춰
자동으로 결과 파일을 생성한다.

예를 들어 원본 데이터에 다음과 같은 정보가 있다.

- 거래처
- 매출일
- 금액
- 담당자
- 부서
- 상품
- 상태

시스템은 데이터를 분석하여 거래처별,
상태별 매출 등을 자동으로 집계한다.

최종 결과는 사용자가 다운로드할 수 있는
Excel 보고서 파일로 제공한다.
