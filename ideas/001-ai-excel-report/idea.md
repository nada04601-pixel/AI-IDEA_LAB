## 1. 아이디어 개요

### 아이디어명
AI Excel 보고서 자동생성기

### 한 줄 설명
사용자가 Excel 또는 CSV 데이터를 업로드하면 AI가 데이터를 분석하고 필요한 항목을 자동으로 매핑하여 회사에서 사용하는 보고서 형태의 Excel 파일을 자동으로 생성해주는 서비스.

---

## 2. 해결하려는 문제

회사에서는 매일 또는 매주 반복적으로 Excel 데이터를 정리하고 보고서를 작성하는 업무가 발생한다.

특히 다음과 같은 반복 작업이 많다.

- 여러 Excel 파일의 데이터 취합
- 컬럼명 및 데이터 형식 정리
- 날짜 형식 통일
- 거래처명 및 회사명 정리
- 필요한 데이터만 추출
- 합계 및 집계
- 기존 Excel 보고서 양식에 데이터 입력
- 반복적인 보고서 생성

이러한 작업은 단순 반복 작업이지만 많은 시간이 소요되며,
담당자가 수작업으로 처리하는 과정에서 오류가 발생할 수 있다.

### 2-1. 누구의 불편인가

| 대상 | 겪는 불편 |
|---|---|
| 영업관리, 경영지원 담당자 | 매주/매월 같은 매출 보고서를 ERP나 시스템 추출 데이터로 다시 만든다. |
| 생산, 품질, 시험 담당자 | 장비나 시스템에서 나온 Raw 데이터를 보고서 양식에 옮겨 적는다. |
| 팀장, 관리자 | 담당자마다 양식과 집계 방식이 달라 결과를 신뢰하기 어렵다. |

### 2-2. 문제의 크기 (검증 필요)

- 보고서 1건 작성에 걸리는 시간: ___ 분 `(인터뷰로 확인)`
- 한 달에 반복되는 횟수: ___ 회 `(인터뷰로 확인)`
- 실수로 인해 재작업이 발생한 경험: ___ `(인터뷰로 확인)`

## 3. 해결 방법

사용자가 Excel 또는 CSV 파일을 업로드하면 시스템이 다음 과정을 자동으로 수행한다.

1. 파일 업로드
2. 보고서 템플릿 선택
3. Excel/CSV 데이터 분석
4. 컬럼 구조 분석
5. AI를 이용한 컬럼 의미 분석
6. 보고서 컬럼과 원본 데이터 컬럼 자동 매핑
7. 사용자 매핑 결과 확인 및 수정
8. 데이터 형식 정규화
9. 데이터 집계 및 가공
10. Excel 보고서 생성
11. 생성된 보고서 미리보기
12. Excel 파일 다운로드
13. 작업 이력 저장

> 변경: 기존에는 템플릿 선택이 8번째였으나, 매핑은 "보고서에 필요한 컬럼"이 정해져야 가능하므로 **2번으로 앞당겼다.**

### 3-1. 핵심 설계 원칙

- **AI는 컬럼 의미 분석과 매핑 추천에만 사용한다.**
- **합계, 집계, 날짜 변환, 셀 입력은 코드가 처리한다.** AI에게 계산을 맡기지 않는다. (정확성과 재현성 확보)
- **AI에는 전체 데이터를 보내지 않는다.** 컬럼명과 샘플 값만 전달한다. (고객 데이터 보호)
- **AI 결과는 사용자가 확인한 뒤에만 확정한다.**

## 7. 사용 예시

### 입력

사용자가 다음과 같은 Excel 파일을 업로드한다.

| 거래처 | 매출일 | 금액 | 담당자 | 부서 | 상품 | 상태 |
|---|---|---:|---|---|---|---|
| (주)대한상사 | 2026-09-01 | 1000000 | 홍길동 | 영업1팀 | A상품 | 완료 |
| 대한상사 | 2026.09.02 | 1360000 | 김철수 | 영업1팀 | B상품 | 완료 |
| ABC테크 | 2026/09/03 | 850000 | 이영희 | 영업2팀 | A상품 | 진행 |

### AI 분석

AI가 데이터의 의미를 분석한다.

예:

```text
거래처 → 고객사
매출일 → 거래일자
금액 → 매출금액
담당자 → 담당자
부서 → 부서
상품 → 상품명
상태 → 처리상태
```

### 정규화 예시

- 날짜: `2026-09-01`, `2026.09.02`, `2026/09/03` → 모두 `YYYY-MM-DD` 형식으로 통일
- 거래처명: `(주)대한상사`와 `대한상사`는 같은 거래처로 묶자고 **제안**하고, 사용자가 확인하면 통합

## 8. 출력 결과

사용자가 업로드한 데이터를 분석한 후,
회사에서 사용하는 Excel 보고서 양식에 맞춰
자동으로 결과 파일을 생성한다.

예를 들어 원본 데이터에 다음과 같은 정보가 있다.

- 거래처
- 매출일
- 금액
- 담당자
- 부서
- 상품
- 상태

시스템은 데이터를 분석하여 거래처별,
상태별 매출 등을 자동으로 집계한다.

최종 결과는 사용자가 다운로드할 수 있는
Excel 보고서 파일로 제공한다.

### 집계 결과 예시 (위 입력 데이터 기준)

**거래처별 매출**

| 거래처 | 매출 합계 |
|---|---:|
| 대한상사 | 2,360,000 |
| ABC테크 | 850,000 |
| **합계** | **3,210,000** |

**상태별 매출**

| 상태 | 건수 | 매출 합계 |
|---|---:|---:|
| 완료 | 2 | 2,360,000 |
| 진행 | 1 | 850,000 |
| **합계** | **3** | **3,210,000** |

## 9. 기존 대안과 차별점

### 9-1. 지금은 어떻게 해결하나

| 대안 | 한계 |
|---|---|
| 수작업 복사/붙여넣기 | 시간이 오래 걸리고 실수가 잦다. |
| Excel 수식, 피벗 테이블 | 만든 사람만 유지할 수 있고, 원본 컬럼 구성이 바뀌면 깨진다. |
| Excel 매크로(VBA) | 개발자 의존적이고 유지보수가 어렵다. |
| Power Query 등 BI 도구 | 일반 사무직이 배우기 어렵다. |
| ChatGPT 등 범용 AI에 파일 첨부 | 매번 지시해야 하고, 결과 양식이 일정하지 않으며, 숫자 계산 정확성을 보장하기 어렵다. |

### 9-2. 이 서비스의 차별점

- **정해진 양식 그대로** 결과물을 만든다. (챗봇처럼 매번 다른 결과가 아님)
- **컬럼명이 바뀌어도** AI가 의미로 매핑해서 대응한다. (수식, 매크로와의 차이)
- **한 번 확정한 매핑을 재사용**해서 두 번째부터는 업로드만으로 끝난다.
- 계산은 코드가 처리해서 **결과가 항상 같고 검증 가능하다.**

## 11. 검증 계획

만들기 전에 아래 순서로 수요를 확인한다.

1. **인터뷰**: 반복 Excel 보고서를 만드는 담당자 5~10명에게 질문한다.
   - 어떤 보고서를, 얼마나 자주, 얼마나 걸려서 만드는가?
   - 지금은 어떻게 해결하고 있는가?
   - 업로드한 데이터를 외부 AI 서비스로 보내도 되는가? (회사 보안 정책)
2. **실제 양식 확보**: 대상 회사의 실제 보고서 양식 1~2개와 샘플 데이터(마스킹 처리)를 받는다.
3. **수작업 시연**: 실제 데이터로 결과물을 먼저 만들어 보여주고 반응을 본다. (코드 없이 스크립트로 가능)
4. **사전 의향 확인**: 사용 의향과 지불 의향을 확인한다.

### 성공 기준 (가정)

- 인터뷰 대상 중 3명 이상이 "지금 당장 쓰고 싶다"고 답한다.
- 1명 이상이 유료 사용 의향을 밝힌다.
- 첫 대상 보고서 1종이 수작업 결과와 **100% 일치**하게 생성된다.
