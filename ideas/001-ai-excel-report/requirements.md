## 1. 프로젝트 개요

### 프로젝트명
AI Excel 보고서 자동생성기

### 프로젝트 목적
Excel 또는 CSV 데이터를 업로드하면
AI가 데이터를 분석하고 보고서에 필요한 데이터를 자동으로 매핑하여
사용자가 지정한 Excel 보고서 양식으로 결과물을 생성한다.

### 프로젝트 상태
MVP 기획

### 대상 사용자
Excel을 이용해 반복적으로 보고서를 작성하는 회사 및 사용자

### 첫 번째 대상 (가정)
보고서 양식이 정해져 있고 매주/매월 같은 보고서를 반복해서 만드는 영업관리 또는 경영지원 담당자 1곳. 범용화는 첫 대상의 문제를 해결한 뒤 진행한다.

---

## 2. 핵심 사용자 시나리오

사용자는 로그인한 뒤 Excel 또는 CSV 파일을 업로드한다.

사용자는 만들고자 하는 **보고서 템플릿을 선택**한다.

시스템은 업로드된 데이터를 분석한다.

AI는 원본 데이터의 컬럼과 선택한 템플릿에서 필요한 컬럼을 분석하여
서로 연결한다.

사용자는 AI가 분석한 결과를 확인하고 수정할 수 있다.

시스템은 날짜, 금액, 거래처명 등을 정규화하고 변경 내역을 보여준다.

사용자가 보고서 생성을 실행하면
시스템은 지정된 Excel 양식에 데이터를 입력한다.

사용자는 결과를 미리보기로 확인하고,
최종적으로 생성된 Excel 보고서를 다운로드한다.

생성 내역은 작업 이력에 저장되어 나중에 다시 조회하고 내려받을 수 있다.

## 4. 업무 규칙 (비즈니스 규칙)

| ID | 규칙 |
|---|---|
| BR-01 | AI는 컬럼 의미 분석과 매핑 추천에만 사용한다. 합계, 집계, 날짜 변환, 셀 입력은 AI가 아닌 코드가 처리한다. |
| BR-02 | AI에는 전체 데이터를 전송하지 않고 컬럼명, 데이터 타입, 소량의 샘플 값만 전송한다. |
| BR-03 | AI가 추천한 매핑은 사용자가 확인하고 확정해야만 다음 단계로 진행할 수 있다. |
| BR-04 | 필수 필드가 매핑되지 않으면 보고서를 생성할 수 없다. |
| BR-05 | 원본 파일과 원본 값은 수정하지 않는다. 정규화와 가공은 복사본에서 수행한다. |
| BR-06 | 거래처명 통합은 자동 확정하지 않고 사용자에게 제안한 뒤 확인을 받는다. |
| BR-07 | 같은 입력과 같은 확정 매핑이면 항상 같은 결과가 생성되어야 한다. |
| BR-08 | 사용자는 본인이 만든 파일과 이력만 조회하고 다운로드할 수 있다. |
| BR-09 | 변환에 실패한 행은 임의로 값을 채우지 않고 오류 목록에 표시하며, 사용자가 제외 여부를 선택한다. |

## 5. 비기능 요구사항 (MVP 기준)

| 구분 | 요구사항 |
|---|---|
| 성능 | 10,000행 기준 업로드부터 보고서 생성까지 30초 이내 (가정) |
| 용량 | 파일당 10MB, 50,000행까지 지원 (가정) |
| 정확성 | 그룹별 합계의 총합이 전체 합계와 일치하는지 검증하고, 불일치 시 생성하지 않는다. |
| 보안 | 업로드 파일은 사용자별로 격리 저장하고, 비밀번호는 해시로 저장하며, 외부 AI로는 BR-02 범위만 전송한다. |
| 보관 | 원본 및 결과 파일은 30일 보관 후 삭제하고 이력 메타 정보만 남긴다. (가정) |
| 호환성 | 최신 Chrome, Edge에서 동작해야 한다. 생성된 .xlsx는 Microsoft Excel에서 오류 없이 열려야 한다. |
| 사용성 | 모든 오류는 사용자가 이해할 수 있는 사유와 함께 표시한다. |
| 가용성 | AI 호출이 실패해도 규칙 기반 매핑으로 대체해 작업을 계속할 수 있어야 한다. |

## 6. 제약 사항 및 가정

- 보고서 템플릿은 개발자가 사전 등록한다. 사용자가 임의의 양식을 올려 등록하는 기능은 MVP에 포함하지 않는다.
- MVP의 첫 템플릿은 "거래처별/상태별 매출 보고서" 1종이다. (실제 대상 회사 양식 확보 후 교체)
- 파일은 한 번에 1개만 처리한다.
- 지원 브라우저는 데스크톱 기준이며 모바일 최적화는 제외한다.
- 배포 형태(웹 서비스 / 사내 설치형)는 미정이며, 웹 서비스를 가정한다.

## 7. MVP 범위 밖

- 여러 파일 동시 취합
- `.xls` 형식 지원
- 사용자 템플릿 업로드 및 편집
- 컬럼 합치기/쪼개기 등 변환 매핑
- 차트 자동 생성, PDF 출력
- 작업 예약 및 자동 실행
- 팀/조직 관리, 권한 등급, 결제 연동, 소셜 로그인
- 외부 시스템(ERP, 구글 시트) 연동
