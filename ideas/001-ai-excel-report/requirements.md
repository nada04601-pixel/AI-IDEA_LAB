# 001. AI Excel 보고서 자동생성기

# 요구사항명세서

## 1. 프로젝트 개요

### 프로젝트명
AI Excel 보고서 자동생성기

### 프로젝트 목적
Excel 또는 CSV 데이터를 업로드하면
AI가 데이터를 분석하고 보고서에 필요한 데이터를 자동으로 매핑하여
사용자가 지정한 Excel 보고서 양식으로 결과물을 생성한다.

### 프로젝트 상태
MVP 기획

### 대상 사용자
Excel을 이용해 반복적으로 보고서를 작성하는 회사 및 사용자

---

## 2. 핵심 사용자 시나리오

사용자는 Excel 또는 CSV 파일을 업로드한다.

시스템은 업로드된 데이터를 분석한다.

AI는 원본 데이터의 컬럼과 보고서에서 필요한 컬럼을 분석하여
서로 연결한다.

사용자는 AI가 분석한 결과를 확인하고 수정할 수 있다.

사용자가 보고서 생성을 실행하면
시스템은 지정된 Excel 양식에 데이터를 입력한다.

최종적으로 사용자는 생성된 Excel 보고서를 다운로드한다.
