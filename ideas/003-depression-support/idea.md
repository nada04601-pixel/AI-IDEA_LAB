## 1. 아이디어 개요

### 아이디어명
우울증 사용자를 위한 제품 (후보 6종 중 선택 예정)

### 한 줄 설명
치료를 대신하지 않고, 우울증을 겪는 사람의 일상을 조금 덜 무겁게 만드는 기록·관리·연결 도구.

---

## 2. 핵심 설계 원칙

우울할 때는 의욕, 에너지, 집중력이 모두 떨어진다. 따라서 다음을 지킨다.

- **입력이 적어야 한다.** 버튼 하나, 이모지 하나로 끝나야 한다.
- **실패해도 죄책감이 들지 않아야 한다.** 연속 기록(streak) 끊김 알림, 못 한 일 강조 등을 하지 않는다.
- **치료를 대신한다고 말하지 않는다.** 진료·상담으로 연결하는 역할에 집중한다.

## 3. 아이디어 후보

| 번호 | 아이디어 | 내용 | 비고 |
|---|---|---|---|
| A | 초저부담 기분 기록 앱 | 하루 한 번 버튼/이모지로 기분 기록. 쌓인 데이터를 진료 때 의사에게 보여줄 요약 리포트(PDF)로 출력. 기록을 빠뜨려도 streak 끊김을 알리지 않음. | **추천 시작점** |
| B | "아주 작은 할 일" 투두 | "일어나서 물 한 잔"처럼 할 일을 최소 단위로 쪼갬. 해낸 일만 보여주고 못 한 일은 조용히 다음 날로 넘김. 행동활성화(behavioral activation) 기법과 맞닿아 있음. | |
| C | 병원·상담 연결 도우미 | 근처 병원/상담센터 찾기, 첫 진료 때 할 말 정리, 예약 전화 대본, 비용 안내(정신건강복지센터 무료 상담, 국가 심리상담 바우처 등)를 한곳에 모음. | **추천 시작점** |
| D | 복약 관리 + 부작용 메모 | 항우울제는 효과가 나타나기까지 몇 주가 걸리고 임의 중단이 잦음. 복약 알림과 "오늘 몸 상태" 메모로 진료 시 소통을 도움. | |
| E | 보호자/지인용 서비스 | 당사자 옆 사람을 위한 가이드: 해야 할 말, 하면 안 되는 말, 위험 신호 알아보기. 보호자가 더 적극적으로 검색하는 경우가 많아 사용자 확보에 유리할 수 있음. | |
| F | 느슨한 연결 커뮤니티 | 대화를 강요하지 않고 "오늘 나 여기 있어요" 정도의 신호만 주고받는 공간. 고립감 완화. | 운영 부담·위험 관리가 가장 큼 |

### 3-1. 추천 시작점

웹개발자 혼자 빠르게 시작하기에는 **A(기분 기록 + 진료용 리포트)** 또는 **C(병원 연결 도우미)**가 범위가 작고 규제 위험도 낮아 현실적이다.

## 4. 꼭 고려할 점

| 항목 | 내용 |
|---|---|
| 위기 대응 | 사용자가 자해·자살 관련 내용을 입력하면 **자살예방상담전화 109** 같은 즉시 연결 경로를 보여준다. 어떤 후보를 고르든 처음부터 넣는다. |
| 의료기기 규제 | "우울증을 치료·개선한다"고 표방하면 국내에서 디지털 치료기기로 분류되어 식약처 허가 대상이 될 수 있다. 처음에는 "기록·관리·연결 도구"로 포지셔닝한다. |
| 민감정보 | 기분·정신건강 데이터는 개인정보보호법상 민감정보로 별도 동의가 필요하다. 로컬 저장을 우선하고 서버 저장은 최소화한다. |
| 당사자 피드백 | 실제 경험자나 정신건강 전문가에게 최소 한 번은 피드백을 받는다. |
