## 1. 한 줄 설명

오늘 유튜브에서 빠르게 조회수가 오르는 쇼츠와, 그 쇼츠들에 공통으로 나오는 키워드를 한 화면에서 보여준다.

## 2. 해결하려는 문제

| 대상 | 겪는 불편 |
|---|---|
| 쇼츠 크리에이터 (특히 시작 단계) | 오늘 무엇을 찍어야 조회수가 나올지 감으로 정한다. 쇼츠 피드를 직접 넘겨보며 유행을 찾는 데 시간이 든다. |
| 마케터·쇼핑몰 운영자 | 요즘 뜨는 소재·해시태그를 빨리 알아야 하는데, 유튜브가 2025-07에 '인기 급상승' 페이지를 없앴다. |
| 일반 시청자 | "요즘 뭐가 유행이야?"를 한 번에 보고 싶다. `(가정)` |

## 3. 핵심 기능 (MVP, 구현됨)

- 국가·기간(6/12/24/48시간)·분야 키워드로 최근 쇼츠 검색
- **떡상 쇼츠 순위:** 시간당 조회수 순. 조회수·좋아요·업로드 시각·길이 표시, 누르면 쇼츠로 이동
- **급상승 키워드 순위:** 여러 떡상 쇼츠에 함께 나온 해시태그·제목 단어. 누르면 해당 영상만 필터
- 할당량 사용량 표시, 샘플 데이터 모드

## 4. 데이터 확보 방법 판단

| 방법 | 장점 | 단점 | 결론 |
|---|---|---|---|
| YouTube Data API `search.list` + `videos.list` | 공식, 무료(하루 10,000단위), 업로드 시각·조회수 정확 | 검색 1회 100단위로 비쌈, 표본 일부만 봄 | **MVP 채택** |
| API `chart=mostPopular` | 1단위로 저렴 | 2025-07 이후 음악·영화·게임 위주, 쇼츠 구분 없음 | 보조 소스 후보 |
| 구글 트렌드(유튜브 검색) | 검색어 자체의 급상승 | 공식 API 없음(알파 API 신청제) | 2단계 검토 |
| 웹 스크래핑 | 데이터 많음 | 약관 위반 위험, 자주 깨짐 | 사용 안 함 |

## 5. 다음 단계

1. **서버 수집 + 공개 페이지:** 지금은 사용자가 각자 API 키를 넣는다. 서버(예: GitHub Actions 예약 실행)에서 1시간마다 수집해 JSON으로 올리면, 키 없이 누구나 보는 "오늘의 떡상 쇼츠" 페이지가 된다. 수익화(애드센스)는 이 형태에서 가능. (002 노바랩 계산소와 같은 모델)
2. **시간대별 추이:** 같은 영상을 1시간 간격으로 다시 조회해 "지난 1시간 증가량"을 계산하면 진짜 '급상승'에 가까워진다. (지금은 업로드 후 평균 속도)
3. **카테고리별 순위:** 먹방·게임·뷰티 등 분야 키워드를 미리 정해 탭으로 제공.
4. **키워드 품질:** 형태소 분석기 도입, 채널명·브랜드 정규화.
5. **AI 요약:** 상위 키워드·제목을 LLM에 넘겨 "오늘의 유행 3줄 요약", "이 키워드로 찍을 쇼츠 아이디어" 생성.

## 6. 확인할 것

- 한 번 분석에 약 200단위 → 하루 공개 서비스로 1시간마다 수집하면 24 × 200 = 4,800단위로 무료 할당량 안에 들어간다. 국가·분야를 늘리면 할당량 증설 신청 필요.
- YouTube API 서비스 약관: 데이터 저장은 30일 이내 갱신 조건 등이 있어, 서버 수집 단계에서 확인.
