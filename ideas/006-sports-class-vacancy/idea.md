## 1. 한 줄 설명

구청·시설관리공단 체육센터(수영장 등) 강좌를 등록해 두면, 정원이 꽉 찬 강좌에 취소 자리가 나거나 접수가 열릴 때 바로 알려준다.

## 2. 해결하려는 문제

| 대상 | 겪는 불편 |
|---|---|
| 직장인 수영 강습 희망자 | 저녁·새벽반은 정기 접수 몇 분 만에 마감된다. 이후 생기는 취소 자리를 잡으려면 사이트를 계속 새로고침해야 한다. |
| 아이 강습을 챙기는 부모 | 유아·어린이 수영은 경쟁이 더 심하다. 접수일·결원 접수일을 놓치기 쉽다. |
| 시니어 | 온라인 접수에 익숙하지 않다. 현장 접수 시작이나 결원 소식을 알면 도움이 된다. `(가정)` |

- 대부분 **인터넷 선착순 + 선결제**다. 결제하지 않은 자리, 당일 취소, 월말 재등록 미신청으로 자리가 다시 나온다.
- 정원이 차지 않으면 **현장 접수**가 추가로 열린다. 기관마다 공지 위치와 방식이 다르다.
- 기관이 직접 제공하는 결원 알림은 찾지 못했다. `(가정: 일부 기관의 '대기 신청' 기능은 따로 확인 필요)`

## 3. 핵심 기능 (MVP 후보)

1. **강좌 등록:** 강좌 페이지 주소를 붙여넣거나 기관 → 시설 → 종목 → 요일·시간으로 고른다.
2. **빈자리 감시:** 서버가 공개된(로그인 없이 보이는) 강좌 목록을 일정 간격으로 확인한다. `마감 → 접수중`, 또는 잔여 인원 `0 → 1 이상`이 되면 알린다.
3. **일정 알림:** 정기 접수 시작, 결원·추가 접수일, 재등록 기간을 미리 알린다 (전날 / 10분 전).
4. **알림 채널:** 웹 푸시(PWA) → 텔레그램 봇 → 카카오 알림톡(유료) 순서로 검토한다.
5. **바로가기:** 알림을 누르면 해당 기관의 신청 페이지로 바로 이동한다. **신청과 결제는 사용자가 직접 한다.**

### 하지 않을 것

- 자동 신청·자동 결제(매크로). 다른 이용자에게 불공정하다. 기관 약관 위반이나 업무방해 소지도 있다.
- 사용자 아이디·비밀번호를 받아 대신 로그인하기.
- 짧은 간격으로 반복 요청해 기관 서버에 부담을 주기.

## 4. 데이터 확보 방법 판단

| 방법 | 장점 | 단점 | 결론 |
|---|---|---|---|
| 서울 열린데이터 '공공서비스예약' OpenAPI (체육시설·교육강좌) | 공식, 공공누리 1유형, 서비스상태·접수기간·예약 바로가기 URL 제공 | 서울만 해당. 하루 1회 갱신이라 실시간 결원 감지 불가. 잔여 인원 필드는 `(미확인)` | **강좌 목록·접수 일정용으로 채택** |
| 각 기관 강좌 목록 페이지 확인 (로그인 없이 공개된 페이지만) | 실시간에 가깝다. 잔여 인원이 보이는 곳이 많다 `(가정)` | 기관마다 구조가 다르다(시스템 업체별 어댑터 필요). 개편되면 깨진다. 약관·robots 확인 필요 | **빈자리 감지용으로 채택. 대상 기관을 좁혀 시작** |
| 로그인해야 보이는 페이지 | 데이터가 가장 정확하다 | 개인 계정 정보 위탁, 약관 위반 위험 | 사용 안 함 |
| 사용자 제보 / 공지 게시판 확인 | 현장 접수·추가 모집 공지를 잡을 수 있다 | 느리다. 정형화가 어렵다 | 보조 수단 |

> 많은 공단이 비슷한 통합예약 솔루션을 쓰는 것으로 보인다 `(가정)`. 솔루션별 어댑터 하나로 여러 기관을 묶을 수 있다면 확장 비용이 크게 줄어든다. 첫 조사에서 확인할 핵심이다.

## 5. 구조 초안

- **수집:** 005 쇼츠 분석기처럼 GitHub Actions 크론으로 시작한다(최소 5분 간격, 실제 실행은 지연될 수 있다). 감시 대상이 늘면 작은 서버나 Cloudflare Workers Cron으로 옮긴다.
- **간격:** 강좌당 5~10분에 한 번. 같은 페이지를 보는 사용자가 여러 명이어도 요청은 한 번만 보낸다(강좌 단위 캐시).
- **저장:** 강좌 ID, 직전 상태, 마지막 확인 시각, 구독자 목록.
- **화면:** 003 마음기록과 같은 Vue + PWA. 내 감시 목록 / 강좌 추가 / 알림 기록.

## 6. 수익화

- 무료: 강좌 2개 감시, 웹 푸시, 10분 간격.
- 유료(월 1,000~2,000원 `(가정)`): 감시 강좌 수 확대, 카카오 알림톡, 5분 간격.
- 기관 쪽 B2G: 공식 '결원 대기 알림' 기능으로 제안한다(장기).
- 접수 일정 캘린더·"우리 동네 수영장 비교" 같은 공개 페이지로 검색 유입과 광고 수익을 노린다(002 노바랩 계산소 모델).

## 7. 위험과 확인할 것

1. **법·약관:** 공개 페이지라도 자동 수집을 금지하는 약관이 있는지, robots.txt를 확인한다. 알림만 하고 신청은 사람이 직접 하는 구조를 지킨다.
2. **공정성 논란:** 알림 사용자만 자리를 가져간다는 불만이 생길 수 있다. "취소 자리를 사람이 보고 직접 신청" 수준으로 유지하고, 문구도 그렇게 쓴다.
3. **결원이 실제로 얼마나 자주 나는지:** 관심 강좌 2~3개를 1~2주 기록해, 알림이 쓸모 있는 빈도인지 먼저 본다.
4. **첫 대상 기관:** 사용자 본인이 다니려는 지역의 공단 1곳으로 시작한다. 잔여 인원이 로그인 없이 보이는지가 선정 기준이다.

## 8. 다음 단계

2. 서울 공공서비스예약 OpenAPI 키 발급 → 실제 응답 필드(서비스상태 값, 잔여석 유무) 확인
3. 1~2주 상태 기록 스크립트(알림 없이 기록만) → 결원 발생 빈도와 시간대 확인
4. 결과가 괜찮으면 웹 푸시 알림 MVP
