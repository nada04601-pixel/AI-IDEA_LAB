# 화면설계서

> 기준 문서: `idea.md` (3. 해결 방법, 3-2 OCR, 3-3 내보내기·백업, 6. 핵심 기능), `tech-stack.md` (2. 데이터 구조)

## 1. 화면 설계 원칙

1. **모바일 우선.** Capacitor 안드로이드 앱, 휴대폰 세로 화면(360~430px) 기준.
2. **입력이 가장 쉬워야 한다.** 결혼식 직후 수백 건을 넣는 상황이 기준이다. 금액은 버튼으로 고르고, 다음 사람으로 바로 넘어간다.
3. **돈 계산하는 느낌을 줄인다.** "빚", "갚기", "손해" 같은 표현을 쓰지 않는다. 받은 돈은 **받음**, 준 돈은 **보냄**으로 쓴다. 차이는 "받은 게 5만원 더 많아요"처럼 사실만 담담하게 쓴다. (idea.md 11. 리스크)
4. **금액 추천은 "기록 참고"로 보여준다.** 추천이 아니라 과거 기록을 근거로 보여주고, 결정은 사용자가 한다.
5. **백업 상태는 항상 보인다.** 서버가 없으므로 기록을 지키는 것이 앱의 책임이다. (idea.md 3-3)
6. **인식(OCR)·가져오기 결과는 확인 후 저장.** 바로 저장하지 않는다.
7. **부모님 세대도 쓸 수 있게.** 기본 글자 크기를 크게, 금액은 콤마를 넣어 크게 표시한다. 설정에서 글자 크기를 키울 수 있다.
8. **회원가입 없음, 인터넷 연결 없음.** (tech-stack.md 1-1)

## 4. 공통 요소

### 4-1. 상단 헤더

```
┌─────────────────────────────────┐
│ 마음장부                    [🔍]  │
└─────────────────────────────────┘
```

- [🔍] 전체 검색: 이름, 행사명, 메모로 검색. 결과는 사람 / 행사로 나눠 보여준다.

### 4-2. 하단 탭 + 기록 버튼

```
│                          ( + 기록 )│  ← 홈·사람·행사 화면 오른쪽 아래
├───────┬───────┬───────┬───────┤
│  ⌂    │  👤   │  📅   │  ⚙    │
│  홈    │  사람  │  행사  │  설정  │
└───────┴───────┴───────┴───────┘
```

### 4-3. 표기 규칙 (전 화면 공통)

| 항목 | 표기 |
|---|---|
| 받은 돈 | **받음** · 초록 계열 `(가정)` |
| 준 돈 | **보냄** · 파랑 계열 `(가정)` |
| 금액 (목록·합계·요약) | **`10만` 처럼 줄여 쓴다.** `50,000` → `5만`, `18,450,000` → `1,845만`. 만 단위로 떨어지지 않으면 `3만 5천`, 천 단위도 아니면 `123,456` |
| 금액 (입력·인식 확인) | S-07·S-08 입력칸 아래 확인 표시와 S-10 인식 결과는 `100,000원` 정확한 표기. 0 하나 차이 오타를 잡기 위해서다. |
| 금액 (문장 안) | "10만원 받았어요"처럼 문장에서는 `원`을 붙인다. |
| 차이 | "받은 게 5만원 더 많아요" / "보낸 게 3만원 더 많아요" / "주고받은 금액이 같아요" |
| 금액 없음 (화환·선물) | `화환`, `선물` 글자로 표시. 합계에는 0원으로 계산 |
| 관계 | 가족 · 친척 · 친구 · 직장 · 지인 · 기타 |
| 행사 종류 | 결혼 · 장례 · 돌잔치 · 생신 · 개업 · 기타 |

- 빨강을 쓰지 않는다. 차이가 "적자·경고"처럼 보이지 않게 한다.

### 4-4. 금액 빠른 선택 (S-07, S-08, S-10 공통)

```
금액
[ 3만 ][ 5만 ][ 10만 ][ 20만 ][ 30만 ][ 직접 ]
```

- 버튼 한 번에 금액이 입력된다. [직접]은 숫자 키패드가 열리고 `만원` 단위 입력을 지원한다. (`15` 입력 → 150,000원)
- 버튼 금액 목록은 설정에서 바꿀 수 있다. `(가정)`

### 4-5. 공통 상태 표시

| 상태 | 표시 방식 |
|---|---|
| 저장 완료 | 짧은 토스트 "저장했어요" (2초) |
| 삭제 | 확인 창 1회, 저장 후 토스트에 [되돌리기] 5초 `(가정)` |
| 빈 상태 | 안내 문구 + 다음 행동 버튼 (예: "아직 기록이 없어요" + [사진으로 지난 기록 등록]) |
| 오류 | 화면 상단 배너, 이유와 다음 행동 안내 |

## S-02 홈

**관련 기능**: 다가오는 경조사 알림, 백업 알림

```
┌─────────────────────────────────┐
│ 마음장부                    [🔍]  │
├─────────────────────────────────┤
│ ┌─ 백업 ──────────────────────┐ │
│ │ ⚠ 마지막 백업 32일 전          │ │
│ │   그 뒤로 48건이 추가됐어요      │ │
│ │              [지금 백업하기]   │ │
│ └─────────────────────────────┘ │
│                                 │
│ 다가오는 경조사                     │
│ ┌─────────────────────────────┐ │
│ │ D-3  김민수 결혼식  11/21(토)  │ │
│ │      대학 동기 · 받음 10만      │ │
│ │                  [보냄 기록]   │ │
│ ├─────────────────────────────┤ │
│ │ D-12 박지영 돌잔치  11/30(일)  │ │
│ │      직장 · 받음 5만            │ │
│ └─────────────────────────────┘ │
│                                 │
│ 최근 기록                          │
│  10/05 이현우  받음  30만         │
│  10/02 최서연  보냄  10만         │
│                      [전체 보기]  │
│                          ( + 기록 )│
├─────────────────────────────────┤
│   홈   │  사람   │  행사   │  설정  │
└─────────────────────────────────┘
```

**백업 카드 상태**

| 상태 | 표시 |
|---|---|
| 백업한 적 없음 + 기록 있음 | "아직 백업하지 않았어요" + [지금 백업하기] (강조) |
| 30일 이상 지남 **또는** 백업 후 30건 이상 추가 `(가정)` | ⚠ "마지막 백업 N일 전 · 그 뒤로 N건 추가" + [지금 백업하기] |
| 최근에 백업함 | ✓ "10월 5일에 백업했어요" 한 줄 (작게) |
| 기록 없음 | 카드 숨김 |

- 다가오는 경조사: 오늘 이후 상대 행사 중 가까운 순 최대 3개. 그 사람에게 **받은 기록이 있으면 한 줄로 함께** 보여준다.
- [보냄 기록]은 S-07을 해당 행사·사람·보냄으로 채워서 연다.
- **행사일이 지났는데 보냄 기록이 없는 상대 행사는 홈에 보여준다.** (기록 누락 방지, 2026-10-07 결정)
  - 위치: "다가오는 경조사" 아래 별도 카드. 최대 3개, 더 있으면 [N개 더 보기].
  - 문구는 재촉하지 않게 쓴다: "기록이 비어 있어요" (O) / "아직 안 냈어요" (X)
  - [보냄 기록]을 누르면 S-07이 해당 행사·사람·보냄으로 채워져 열린다.
  - 보내지 않았거나 기록할 필요가 없는 행사는 [기록 안 함]으로 카드에서 뺄 수 있다. 행사 상세(S-06)에서는 계속 보인다.

```
│ 기록이 비어 있는 경조사              │
│ ┌─────────────────────────────┐ │
│ │ 09/14 정우진 부친상             │ │
│ │       친구 · 받음 5만           │ │
│ │          [기록 안 함][보냄 기록] │ │
│ └─────────────────────────────┘ │
```

├─────────────────────────────────┤

- 연락처에서 불러오기는 사람 추가 화면에서 제공한다. 이름만 가져오고 전화번호는 저장하지 않는다. (tech-stack.md 1장)

## S-07 내역 입력

**관련 기능**: 받은 돈·보낸 돈 기록, 상대 행사 등록, 금액 추천(기록 참고)

```
┌─────────────────────────────────┐
│ ✕  기록하기                  [저장] │
├─────────────────────────────────┤
│ [   받음   |   보냄   ]            │
│                                 │
│ 누구와                             │
│ [김민__________________]         │
│  ┌ 김민수 · 대학 동기               │
│  ├ 김민지 · 직장                   │
│  └ + "김민" 새 사람으로 추가         │
│                                 │
│ 어떤 행사                          │
│ [김민수 결혼식 2026-11-21 ▾]       │
│  (+ 새 행사)                       │
│                                 │
│ ┌─ 기록 참고 ─────────────────┐   │
│ │ 2024-05-18 내 결혼식에서       │   │
│ │ 김민수 님께 10만원 받았어요.     │   │
│ └─────────────────────────────┘   │
│                                 │
│ 금액                              │
│ [3만][5만][10만][20만][30만][직접]  │
│ 100,000원                        │
│                                 │
│ 방식 [현금][계좌이체][화환][선물]     │
│ 참석 [참석][불참][모름]              │
│ 메모 [__________________]        │
└─────────────────────────────────┘
```

**동작**

- 이름을 입력하면 기존 사람이 자동 완성된다. 없으면 새 사람으로 추가된다. 이름이 같은 사람이 여럿이면 소속으로 고른다.
- **기록 참고**는 "보냄"이고, 그 사람에게 받은 기록이 있을 때만 보인다. 문구는 사실만 쓴다. "10만원 내세요" 같은 지시형 문구를 쓰지 않는다.
- 상대 행사 모드 ([+ 기록] → 상대 경조사 등록): 사람·행사 종류·날짜를 먼저 입력하고, 금액은 비워 둔 채 저장할 수 있다. (청첩장만 받은 상태). 저장 시 D-day 알림 켜기 여부를 묻는다.
- 처음으로 알림을 켤 때 안드로이드 알림 권한을 요청한다.

## S-08 빠른 연속 입력

**관련 기능**: 빠른 연속 입력 (내 행사 명단)

결혼식 방명록을 보며 수십~수백 건을 연달아 넣는 화면. **한 사람 입력 = 이름 입력 + 금액 버튼 1번 + 다음**이 목표다.

```
┌─────────────────────────────────┐
│ ✕  내 결혼식 명단 입력       [완료]  │
├─────────────────────────────────┤
│ 이번에 입력: 23명 · 235만            │
│                                 │
│ 이름  [이현우_______________]      │
│ 관계  [가족][친척][친구][직장][지인]  │
│       (직전 선택 유지)              │
│ 금액  [3만][5만][10만][20만][직접]  │
│ 방식  [현금 ●] [계좌] [화환]         │
│       (직전 선택 유지)              │
│                                 │
│ [       저장하고 다음 (↵)      ]     │
├─────────────────────────────────┤
│ 방금 입력한 사람                    │
│  23 이현우  친척  30만  [수정]       │
│  22 박지영  직장   5만  [수정]       │
│  21 김민수  친구  10만  [수정]       │
└─────────────────────────────────┘
```

- 저장하면 이름 칸이 비워지고 키보드가 다시 이름 칸으로 간다. 관계·방식은 직전 값을 유지한다. (같은 테이블 하객이 연달아 나오는 경우가 많다)
- 금액 버튼은 **금액만 입력하고 저장하지 않는다.** 반드시 [저장하고 다음]을 눌러야 저장된다. 버튼을 잘못 눌러 틀린 금액이 저장되는 일을 막기 위해서다. (2026-10-07 결정)
- 이미 등록된 이름이면 "이미 있는 김민수(대학 동기)인가요?" 한 줄로 묻는다. [같은 사람] / [다른 사람]
- [완료] 시 입력 요약 후, 많이 입력했으면(예: 20건 이상) **백업 제안**을 띄운다. (idea.md 3-3)

## S-11 내보내기·백업

**관련 기능**: 원탭 백업, 엑셀·CSV·PDF 내보내기, 비밀번호(선택)

```
┌─────────────────────────────────┐
│ ←  내보내기·백업                    │
├─────────────────────────────────┤
│ ┌─ 전체 백업 ─────────────────┐   │
│ │ 사람 214 · 행사 31 · 기록 402  │   │
│ │ 마지막 백업: 10월 5일           │   │
│ │                             │   │
│ │ [ ] 비밀번호 걸기 (선택)        │   │
│ │                             │   │
│ │ [      백업 파일 만들기      ]  │   │
│ │ 카카오톡 나에게, 드라이브, 이메일  │   │
│ │ 중에서 저장할 곳을 고를 수 있어요. │   │
│ └─────────────────────────────┘   │
│                                 │
│ 보기 좋은 파일로 내보내기             │
│ 형식  [엑셀 ●] [CSV] [PDF 명단]     │
│ 범위  [전체 ▾]                     │
│       (전체 / 행사별 / 기간 / 사람)   │
│ [        내보내기         ]         │
│                                 │
│ 다른 휴대폰·엑셀에서 가져오기 → S-12  │

**비밀번호 걸기를 켜면 (idea.md 3-3)**

```
│ 비밀번호     [__________]          │
│ 한 번 더     [__________]          │
│ ⓘ 비밀번호를 잊으면 이 백업은         │
│   복원할 수 없어요. 서버가 없어서      │
│   찾아 드릴 방법이 없어요.            │
```

- 비밀번호 걸기는 **기본 꺼짐**. 비밀번호는 저장하지 않으므로 매번 입력한다.
- **비밀번호 없이 [백업 파일 만들기]를 누르면 공유 창 직전에 매번 안내를 띄운다.** "다시 보지 않기"는 두지 않는다. (2026-10-07 결정)

```
┌─────────────────────────────────┐
│ 비밀번호 없이 백업할까요?             │
│                                 │
│ 이 파일에는 이름과 금액이 그대로       │
│ 들어 있어요. 카카오톡·이메일로 보내면  │
│ 파일을 받은 사람도 볼 수 있어요.       │
│                                 │
│ [비밀번호 걸기]   [그대로 백업하기]    │
└─────────────────────────────────┘
```

  - [비밀번호 걸기]는 비밀번호 입력 칸을 펼친 화면으로 돌아간다.
  - 엑셀·CSV·PDF 내보내기에도 같은 안내를 띄운다. 비밀번호를 걸 수 없는 형식이라 [취소] / [내보내기]만 둔다.
- 백업 완료 후 홈의 백업 카드가 ✓ 상태로 바뀐다.
- 엑셀·CSV·PDF는 비밀번호를 걸지 않는다. 사람이 바로 열어 보는 용도다.
- 파일 이름: `마음장부_백업_2026-10-07.json`, `마음장부_내결혼식_명단.xlsx`

│   (.json)        │            │ 지금 휴대폰에는     │
│ · 엑셀 (.xlsx)    │            │ 기록 12건이 있어요.  │
│ · CSV            │            │                  │
│                  │            │ ○ 합치기 (추천)     │
│ [엑셀 양식 받기]    │            │   중복 9건은 건너뜀 │
│                  │            │ ○ 덮어쓰기          │
│                  │            │   지금 기록을 지우고 │
│                  │            │   백업으로 바꿈     │
│                  │            │                  │
│                  │            │ [    가져오기    ]  │
└──────────────────┘            └──────────────────┘
```

**흐름**

1. 파일 선택 → 형식 자동 판별.
2. 비밀번호가 걸린 백업이면 비밀번호 입력. 틀리면 "비밀번호가 맞지 않아요" (tech-stack.md 5-1).
3. 미리보기: 건수·기간·중복 건수. 휴대폰에 기록이 없으면 합치기/덮어쓰기 선택 없이 바로 가져온다.
4. **덮어쓰기**는 한 번 더 확인하고, 실행 전 현재 데이터를 임시 보관해 [되돌리기]를 1회 제공한다. (tech-stack.md 5-2)
5. 이름은 같지만 id가 다른 사람이 있으면 **"같은 사람인가요?"** 목록을 보여준다.

```
│ 같은 사람인지 확인해 주세요 (3)        │
│ 김민수 (대학 동기) ↔ 김민수 (대학 동기) │
│        [같은 사람] [다른 사람]        │
│ 박지영 (직장) ↔ 박지영 (교회)         │
│        [같은 사람] [다른 사람]        │
```

**엑셀·CSV 가져오기**

- [엑셀 양식 받기]: 빈 가져오기 양식(= 내보내기 "전체 내역" 시트와 같은 열)을 공유 창으로 내보낸다.
- 가져올 때 열 이름이 다르면 열 연결 화면을 보여준다. (예: "축의금" 열 → 금액) `(가정)`
- 금액·날짜를 읽을 수 없는 줄은 목록으로 보여주고 제외할지 고치게 한다.
